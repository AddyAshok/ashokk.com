Spring Security Interview Questions and Answers

Questions asked to experienced developers, grouped by topic, with precise answers. Read the linked topic pages for the details.

Basics and default behavior

QuestionAnswer
What happens when you add spring-boot-starter-security?Boot creates a default SecurityFilterChain (anyRequest().authenticated(), formLogin, httpBasic), an in-memory user 'user' with a generated password, CSRF and default headers.
Authentication vs authorization?Authentication proves identity (401). Authorization decides permissions (403).
How does Spring Security work in a web app?DelegatingFilterProxy delegates to FilterChainProxy, which picks a SecurityFilterChain: an ordered list of filters that authenticate, store the SecurityContext, protect and authorize before the DispatcherServlet.
What is SecurityContextHolder?A holder of the current SecurityContext (Authentication) in a ThreadLocal, filled by authentication filters and cleared after the request.
What is FilterChainProxy?The bean that holds all SecurityFilterChains, selects the first matching one, and applies the HTTP firewall.
How do you define security in Spring Security 6?With SecurityFilterChain beans and the lambda DSL. WebSecurityConfigurerAdapter was removed.

Authentication internals

QuestionAnswer
AuthenticationManager vs AuthenticationProvider?The manager is the API. ProviderManager tries each provider that supports the token type.
What does DaoAuthenticationProvider do?Loads the user via UserDetailsService, checks account flags, verifies the password with PasswordEncoder, then returns an authenticated token.
Why is {bcrypt} in front of hashes?DelegatingPasswordEncoder stores the algorithm id, so several algorithms can coexist and be upgraded.
How do you store passwords?Hash with an adaptive salted algorithm (bcrypt, Argon2) via PasswordEncoder. Never plain text or fast hashes.
How would you add 2FA?A custom AuthenticationProvider verifying password and TOTP, or a two-step flow with a pre-authentication state.
How do you protect against brute force?Slow hashing, lockout with expiry, rate limiting per IP and user, CAPTCHA, MFA, generic error messages.

Authorization

QuestionAnswer
hasRole vs hasAuthority?hasRole adds the ROLE_ prefix. Roles are coarse groups, authorities are fine-grained permissions.
URL security vs method security?URL rules are checked by AuthorizationFilter. Method security uses AOP proxies with SpEL and arguments. Use both.
Why is my @PreAuthorize ignored?Missing @EnableMethodSecurity, self invocation, private method, or a bean not managed by Spring.
What is IDOR / BOLA?Accessing another user's object by changing an id because only login was checked. Fix with per-object authorization.

Web protections

QuestionAnswer
What is CSRF and when can you disable it?A cross-site request using the victim's cookie. Disable only for stateless APIs that use an Authorization header token, not cookies.
What is CORS? Does it secure my API?A browser rule about which origins may call your API from JavaScript. It does not secure the API against other clients.
What is session fixation?Forcing a known session id on a victim. Prevented by changing the session id after login.
Which security headers matter?CSP, HSTS, X-Frame-Options or frame-ancestors, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.

JWT and OAuth2

QuestionAnswer
What is a JWT?A signed, base64url encoded token: header.payload.signature. The payload is readable by anyone. The signature proves integrity.
Advantages of JWT?Stateless, scalable, works across services and domains, carries claims, no session store.
Disadvantages of JWT?Hard to revoke, larger, payload not secret, stale claims until expiry, theft risk, more crypto and key management.
How do you revoke a JWT?Short expiry plus refresh tokens, a deny list of jti in Redis, a per-user token version, or use opaque tokens with introspection.
HS256 vs RS256?HS256 uses one shared secret for signing and verifying. RS256 uses a private key to sign and a public key to verify, so resource servers cannot forge tokens.
Where to store JWT in a browser?In memory (with refresh cookie) or an HttpOnly Secure SameSite cookie. Avoid localStorage because of XSS.
What is the alg none attack?Sending a token with alg none so an insecure library skips verification. Prevent by pinning the expected algorithm.
OAuth2 vs OIDC?OAuth2 authorizes access to resources. OIDC adds authentication with the ID token.
Which OAuth2 flow for a SPA?Authorization Code with PKCE.

Scenario questions

  • A user changes /api/orders/5 to /api/orders/6 and sees another person's order. What is wrong and how do you fix it? Missing object level authorization. Check ownership in the service (or an AuthorizationManager or @PreAuthorize with a permission bean) and write a test.
  • Logout with JWT does nothing: the token still works. Why? The server is stateless. Use short access tokens, revoke the refresh token, and a deny list or token version if instant revocation is needed.
  • Your API returns 403 for POST but GET works. Why? CSRF token missing. Send it, or disable CSRF for a stateless token API.
  • You must support 50000 concurrent logged-in users on 10 instances. Sessions or JWT? Both work. Sessions need shared storage (Redis). JWT needs no shared state but needs a revocation strategy. Decide by revocation needs and architecture.
  • How do you secure service to service calls? OAuth2 client credentials with short-lived tokens or mTLS, network policies, and least-privilege scopes.

Common mistake: Answering only with definitions. Interviewers want reasons and trade-offs: why, when not, what breaks, and how you would test it.

Interview questions

Which topics are asked most for senior roles?

The filter chain and default behavior, authentication flow internals, JWT trade-offs and revocation, OAuth2 flows, CSRF and CORS, method security pitfalls and authorization design (IDOR).

How do I prepare quickly?

Build a small API with form login, then JWT with refresh tokens, then Keycloak. Break it on purpose (IDOR, no CSRF) and fix each problem.

What shows real experience?

Talking about failures: stale roles in a JWT, self-invocation with @PreAuthorize, CORS preflight blocked by security, and how logs and tests caught them.
