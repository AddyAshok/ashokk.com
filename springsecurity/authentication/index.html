Authentication

Login mechanisms, users and password hashing, custom providers with lockout, and session management.

Authentication Mechanisms ComparedSpring Security supports many ways to prove identity.Users, UserDetailsService and Password EncodingWhere users are stored and how passwords are hashed decide how safe your system is when the database leaks.Custom AuthenticationProvider, Handlers, Events and Account LockoutWhen passwords are not the only proof (OTP codes, API secrets, LDAP, external services), you write an AuthenticationProvider.Session Management: Fixation, Concurrency, Timeouts and Spring SessionFor session based applications, the session id is the credential.
