JWT Authentication in Spring Security: Complete Implementation with RS256

A complete, working design: users log in with a password, the server signs a short-lived JWT with an RSA private key, and every API request is verified with the public key using Spring Security's built-in resource server support. No hand-written token parsing. It also shows the internal workflow of the bearer token filter.

Architecture

POST /auth/login {email, password}
   └─ AuthenticationManager ─► DaoAuthenticationProvider ─► DbUserDetailsService + BCrypt      (password check)
   └─ JwtEncoder signs the token with the PRIVATE key (RS256, kid in header)
   ◄─ { "accessToken": "eyJ..." }

GET /api/orders   Authorization: Bearer eyJ...
   └─ Security filter chain (stateless)
        BearerTokenAuthenticationFilter
          1. BearerTokenResolver: read the Authorization header, strip "Bearer "
          2. BearerTokenAuthenticationToken(tokenString)
          3. ProviderManager ─► JwtAuthenticationProvider
                4. JwtDecoder.decode(token):  parse ─► check alg is RS256 ─► verify signature with the PUBLIC key
                                              ─► validators: exp/nbf (JwtTimestampValidator), iss, aud, custom
                5. JwtAuthenticationConverter: claims ─► authorities (roles / permissions)
                6. JwtAuthenticationToken (authenticated) ─► SecurityContextHolder
          errors: invalid token ─► BearerTokenAuthenticationEntryPoint ─► 401 + WWW-Authenticate: Bearer error="invalid_token"
                  not enough rights ─► BearerTokenAccessDeniedHandler ─► 403
        AuthorizationFilter ─► hasAuthority(...) rules ─► controller

Keys: encoder and decoder

import com.nimbusds.jose.JOSEException;
import com.nimbusds.jose.jwk.JWKSet;
import com.nimbusds.jose.jwk.RSAKey;
import com.nimbusds.jose.jwk.source.ImmutableJWKSet;

@Configuration
public class JwtKeyConfig {

    // DEMO: generates a new key at every start (all tokens become invalid after a restart).
    // PRODUCTION: load the private key from a secret store or a mounted file, and keep the same key across instances.
    @Bean
    public RSAKey rsaKey() throws Exception {
        KeyPairGenerator generator = KeyPairGenerator.getInstance("RSA");
        generator.initialize(2048);
        KeyPair pair = generator.generateKeyPair();
        return new RSAKey.Builder((RSAPublicKey) pair.getPublic())
                .privateKey(pair.getPrivate())
                .keyID(UUID.randomUUID().toString())
                .build();
    }

    @Bean
    public JwtEncoder jwtEncoder(RSAKey rsaKey) {
        return new NimbusJwtEncoder(new ImmutableJWKSet<>(new JWKSet(rsaKey)));
    }

    @Bean
    public JwtDecoder jwtDecoder(RSAKey rsaKey) throws JOSEException {
        return NimbusJwtDecoder.withPublicKey(rsaKey.toRSAPublicKey())
                .signatureAlgorithm(SignatureAlgorithm.RS256)          // PIN the algorithm: nothing else is accepted
                .build();
    }
}

Token service

@Service
public class TokenService {

    private static final String ISSUER = "https://auth.shop.example";
    private static final String AUDIENCE = "shop-api";

    private final JwtEncoder encoder;
    private final RSAKey rsaKey;

    public TokenService(JwtEncoder encoder, RSAKey rsaKey) { this.encoder = encoder; this.rsaKey = rsaKey; }

    public String createAccessToken(Authentication auth) {
        Instant now = Instant.now();
        List<String> authorities = auth.getAuthorities().stream().map(GrantedAuthority::getAuthority).toList();

        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(ISSUER)
                .audience(List.of(AUDIENCE))
                .subject(auth.getName())
                .issuedAt(now)
                .expiresAt(now.plus(Duration.ofMinutes(10)))               // short lived
                .id(UUID.randomUUID().toString())                          // jti for revocation
                .claim("authorities", authorities)
                .build();

        JwsHeader header = JwsHeader.with(SignatureAlgorithm.RS256).keyId(rsaKey.getKeyID()).build();
        return encoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
    }
}

Security configuration

@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {

    @Bean
    SecurityFilterChain api(HttpSecurity http) throws Exception {
        http
            .csrf(csrf -> csrf.disable())                                              // stateless, Authorization header
            .cors(Customizer.withDefaults())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(a -> a
                .requestMatchers("/auth/login", "/auth/refresh", "/actuator/health").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated())
            .oauth2ResourceServer(o -> o.jwt(j -> j.jwtAuthenticationConverter(jwtAuthenticationConverter())));
        return http.build();
    }

    // read authorities from our own claim, without adding the default SCOPE_ prefix
    private JwtAuthenticationConverter jwtAuthenticationConverter() {
        JwtGrantedAuthoritiesConverter authorities = new JwtGrantedAuthoritiesConverter();
        authorities.setAuthoritiesClaimName("authorities");
        authorities.setAuthorityPrefix("");
        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(authorities);
        return converter;
    }

    @Bean
    AuthenticationManager authenticationManager(AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();            // uses your UserDetailsService and PasswordEncoder beans
    }

    @Bean
    PasswordEncoder passwordEncoder() { return PasswordEncoderFactories.createDelegatingPasswordEncoder(); }
}

Login endpoint and a protected endpoint

public record LoginRequest(@NotBlank String email, @NotBlank String password) { }
public record TokenResponse(String accessToken, String tokenType, long expiresIn) { }

@RestController
@RequestMapping("/auth")
public class AuthController {

    private final AuthenticationManager authenticationManager;
    private final TokenService tokenService;

    public AuthController(AuthenticationManager authenticationManager, TokenService tokenService) {
        this.authenticationManager = authenticationManager;
        this.tokenService = tokenService;
    }

    @PostMapping("/login")
    public TokenResponse login(@Valid @RequestBody LoginRequest request) {
        Authentication auth = authenticationManager.authenticate(                      // throws BadCredentialsException -> 401
                UsernamePasswordAuthenticationToken.unauthenticated(request.email(), request.password()));
        return new TokenResponse(tokenService.createAccessToken(auth), "Bearer", 600);
    }
}

@RestController
@RequestMapping("/api")
class OrderController {

    @GetMapping("/orders")
    List<String> orders(@AuthenticationPrincipal Jwt jwt) {                            // the verified token
        return List.of("order for " + jwt.getSubject());
    }

    @GetMapping("/admin/stats")
    @PreAuthorize("hasAuthority('ROLE_ADMIN')")
    Map<String, Object> stats(JwtAuthenticationToken auth) {
        return Map.of("user", auth.getName(), "claims", auth.getToken().getClaims().keySet());
    }
}

Alternative: your own OncePerRequestFilter

Older tutorials write a filter that parses the header, verifies the token with a library such as jjwt, and sets the SecurityContext. It works, but you must remember every check (algorithm, exp, iss, aud, clock skew, error handling). The built-in resource server support does all of it, is tested and maintained by the Spring team, and integrates with JWKS, opaque tokens and multi-tenancy. Prefer it unless you have a special requirement.

// The structure of a hand-written filter (for understanding only)
public class JwtAuthFilter extends OncePerRequestFilter {
    private final JwtDecoder decoder;
    private final JwtAuthenticationConverter converter;

    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain) throws ServletException, IOException {
        String header = req.getHeader(HttpHeaders.AUTHORIZATION);
        if (header != null && header.startsWith("Bearer ")) {
            try {
                Jwt jwt = decoder.decode(header.substring(7));                  // verifies signature AND validators
                SecurityContextHolder.getContext().setAuthentication(converter.convert(jwt));
            } catch (JwtException e) {
                SecurityContextHolder.clearContext();
                res.sendError(HttpServletResponse.SC_UNAUTHORIZED);
                return;
            }
        }
        chain.doFilter(req, res);
    }
}

Common mistake: Generating the RSA key at every startup in production, or with several instances. Tokens issued by one instance are rejected by the other and by the same instance after a restart. Load one stable key from a secret store, and plan rotation with key ids (kid).

Interview questions

Why RS256 and not HS256?

With RS256 only the auth server holds the private key. Other services verify with the public key and cannot create tokens. With HS256 every verifier knows the signing secret and could forge tokens.

What does oauth2ResourceServer().jwt() add to the chain?

BearerTokenAuthenticationFilter with a JwtAuthenticationProvider, a JwtDecoder for verification and validation, and entry point and access denied handlers for 401 and 403 with Bearer headers.

Why put the authorities claim in the token?

So the API can authorize without a database call. The price is stale permissions until the token expires, so keep it short and consider a token version check.
