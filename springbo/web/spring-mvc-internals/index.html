Spring MVC Internals

When a request reaches your controller, many components work behind the scenes. Knowing this flow helps you debug and choose between filters, interceptors and advice.

Request flow

Client
  │  HTTP request
  ▼
Servlet container (embedded Tomcat) ── thread from the pool
  ▼
Filter chain (Servlet Filters: security, CORS, logging)
  ▼
DispatcherServlet  (front controller)
  ├─ 1. HandlerMapping      finds the controller method for the URL
  ├─ 2. HandlerInterceptor.preHandle()
  ├─ 3. HandlerAdapter      resolves arguments (@PathVariable, @RequestBody ...)
  │       └─ HttpMessageConverter: JSON → Java object
  ├─ 4. Controller method runs
  ├─ 5. HttpMessageConverter: Java object → JSON
  ├─ 6. HandlerInterceptor.postHandle() / afterCompletion()
  └─ 7. On exception: HandlerExceptionResolver → @ExceptionHandler / @ControllerAdvice
  ▼
Response to the client

Filter example: request id

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.UUID;
import org.slf4j.MDC;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

@Component
public class RequestIdFilter extends OncePerRequestFilter {

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response,
                                    FilterChain chain) throws ServletException, IOException {
        String id = UUID.randomUUID().toString();
        MDC.put("requestId", id);                       // available in every log line
        response.setHeader("X-Request-Id", id);
        try {
            chain.doFilter(request, response);
        } finally {
            MDC.clear();
        }
    }
}

Interceptor example and registration

public class TimingInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest req, HttpServletResponse res, Object handler) {
        req.setAttribute("start", System.currentTimeMillis());
        return true;                                    // false stops the request
    }

    @Override
    public void afterCompletion(HttpServletRequest req, HttpServletResponse res,
                                Object handler, Exception ex) {
        long ms = System.currentTimeMillis() - (long) req.getAttribute("start");
        System.out.println(req.getRequestURI() + " took " + ms + " ms");
    }
}

@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(new TimingInterceptor()).addPathPatterns("/api/**");
    }

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOrigins("https://myfrontend.com")
                .allowedMethods("GET", "POST", "PUT", "DELETE");
    }
}

Threading model

  • Tomcat uses one thread per request from a pool (server.tomcat.threads.max, default 200).
  • A blocking database call holds the thread until it finishes.
  • With Java 21 you can use virtual threads: spring.threads.virtual.enabled=true. Blocking code then scales much better, without reactive programming.

HttpMessageConverter

Converters translate between HTTP bodies and Java objects. Boot registers a JSON converter (Jackson), a String converter and others. The Accept and Content-Type headers decide which converter is used.

Common mistake: Doing security or logging work in the controller of every endpoint. Cross-cutting request work belongs in a filter or interceptor.

Interview questions

What is the DispatcherServlet?

The front controller of Spring MVC. Every request comes to it and it delegates to handler mappings, adapters, converters and view or exception resolvers.

Does a filter run before or after an interceptor?

Filters run first (before the DispatcherServlet). Interceptors run inside the DispatcherServlet, around the controller.

How do I change the JSON format of dates?

Configure Jackson through properties, for example spring.jackson.serialization.write-dates-as-timestamps=false (Jackson 2). Boot 4 uses Jackson 3 with similar properties under spring.jackson.*.
