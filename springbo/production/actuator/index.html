Actuator and Monitoring

Actuator gives your application production features: health checks, metrics, environment information and more, all as HTTP endpoints. It is the base for monitoring with Prometheus and Grafana.

Setup

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>
management.endpoints.web.exposure.include=health,info,metrics,prometheus,loggers
management.endpoint.health.show-details=when-authorized
management.endpoint.health.probes.enabled=true
# run management endpoints on a separate internal port
management.server.port=9090

Important endpoints

EndpointShows
/actuator/healthUP or DOWN, plus details for database, disk, and so on
/actuator/infoApplication information (name, version, git commit)
/actuator/metricsMetrics such as jvm.memory.used, http.server.requests
/actuator/prometheusAll metrics in Prometheus format
/actuator/loggersView and change log levels at runtime
/actuator/env, /configpropsConfiguration values (sensitive, protect them)
/actuator/beans, /mappings, /conditionsAll beans, URL mappings and auto-configuration decisions
/actuator/threaddump, /heapdumpDiagnostics (sensitive, protect them)

By default only health is exposed over HTTP. Expose only what you need and protect the rest with Spring Security or a separate management port.

Liveness and readiness (Kubernetes)

GET /actuator/health/liveness   → is the process alive? (restart if DOWN)
GET /actuator/health/readiness  → can it accept traffic? (remove from load balancer if DOWN)

Custom health indicator

// Boot 3.x imports. In Boot 4 the health classes moved to org.springframework.boot.health.*
import org.springframework.boot.actuate.health.Health;
import org.springframework.boot.actuate.health.HealthIndicator;

@Component
public class PaymentGatewayHealth implements HealthIndicator {

    private final PaymentClient client;
    public PaymentGatewayHealth(PaymentClient client) { this.client = client; }

    @Override
    public Health health() {
        try {
            client.ping();
            return Health.up().withDetail("gateway", "reachable").build();
        } catch (Exception ex) {
            return Health.down(ex).withDetail("gateway", "unreachable").build();
        }
    }
}

Custom metrics with Micrometer

@Service
public class CheckoutService {

    private final Counter orders;
    private final Timer timer;

    public CheckoutService(MeterRegistry registry) {
        this.orders = Counter.builder("shop.orders.created").description("Orders created").register(registry);
        this.timer = Timer.builder("shop.checkout.time").register(registry);
    }

    public void checkout() {
        timer.record(() -> {
            // business work
            orders.increment();
        });
    }
}
<dependency>
    <groupId>io.micrometer</groupId>
    <artifactId>micrometer-registry-prometheus</artifactId>
    <scope>runtime</scope>
</dependency>
# prometheus.yml
scrape_configs:
  - job_name: shop
    metrics_path: /actuator/prometheus
    static_configs:
      - targets: ['localhost:9090']

Prometheus collects the metrics and Grafana draws dashboards. Alert on error rate, response time (p95, p99), JVM memory, and database pool usage (hikaricp.connections.active).

Info endpoint

management.info.env.enabled=true
info.app.name=shop
info.app.version=1.0.0

Common mistake: Exposing all Actuator endpoints (include=*) on the public internet. env, heapdump and beans can leak secrets and internals. Expose only what you need and secure them.

Interview questions

What is the difference between liveness and readiness?

Liveness tells whether the application should be restarted. Readiness tells whether it can receive traffic right now, for example after startup or during a database outage.

What is Micrometer?

The metrics facade used by Spring Boot, like SLF4J for metrics. It sends the same metrics to Prometheus, Datadog, CloudWatch and others.

How do I trace a request across services?

Add Micrometer Tracing with OpenTelemetry. Every request gets a trace id that is passed between services and shown in the logs.
