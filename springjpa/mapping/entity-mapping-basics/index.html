Entity Mapping Basics: @Entity, @Column, Types and Converters

Mapping tells Hibernate how a class corresponds to a table. This page covers the annotations you use every day, how Java types map to SQL types, enums, dates, large objects and converters, plus the rules an entity class must follow.

Rules for an entity class

  • Annotated with @Entity and has an identifier (@Id).
  • Has a no-argument constructor (public or protected). Hibernate creates instances by reflection.
  • Not final, and no final methods that Hibernate should override: proxies for lazy loading are subclasses.
  • Fields are not final (Hibernate sets them). Records cannot be entities (they are final and immutable).
  • Access type is decided by where @Id is placed: on a field means field access (recommended), on a getter means property access.
@Entity
@Table(name = "products",
       uniqueConstraints = @UniqueConstraint(name = "uk_products_sku", columnNames = "sku"),
       indexes = { @Index(name = "idx_products_category", columnList = "category"),
                   @Index(name = "idx_products_created", columnList = "created_at") })
public class Product {

    @Id
    @GeneratedValue(strategy = GenerationType.SEQUENCE)
    private Long id;

    @Column(name = "sku", nullable = false, length = 40, updatable = false)
    private String sku;

    @Column(nullable = false, length = 120)
    private String name;

    @Column(nullable = false, precision = 12, scale = 2)          // money: BigDecimal, never double
    private BigDecimal price;

    @Enumerated(EnumType.STRING)                                  // store the NAME. ORDINAL breaks when constants are reordered
    @Column(nullable = false, length = 20)
    private ProductStatus status = ProductStatus.DRAFT;

    @Lob                                                          // large text (CLOB); use sparingly and lazily
    private String description;

    @Transient                                                    // not persisted
    private BigDecimal priceWithTax;

    @Column(name = "created_at", nullable = false, updatable = false)
    private Instant createdAt = Instant.now();

    protected Product() { }                                       // for Hibernate
    public Product(String sku, String name, BigDecimal price) { this.sku = sku; this.name = name; this.price = price; }

    // getters, setters only where needed
}

AttributeConverter: custom types

@Converter(autoApply = false)
public class TagsConverter implements AttributeConverter<Set<String>, String> {
    @Override
    public String convertToDatabaseColumn(Set<String> tags) {
        return tags == null || tags.isEmpty() ? null : String.join(",", new TreeSet<>(tags));
    }
    @Override
    public Set<String> convertToEntityAttribute(String db) {
        return db == null ? new HashSet<>() : new HashSet<>(Arrays.asList(db.split(",")));
    }
}

@Convert(converter = TagsConverter.class)
@Column(length = 500)
private Set<String> tags = new HashSet<>();

// value object stored as one column
@Converter(autoApply = true)                                      // applied to EVERY Money attribute automatically
public class MoneyConverter implements AttributeConverter<Money, BigDecimal> {
    public BigDecimal convertToDatabaseColumn(Money m) { return m == null ? null : m.amount(); }
    public Money convertToEntityAttribute(BigDecimal v) { return v == null ? null : new Money(v); }
}

Converters cannot be used on ids, versions or relations, and queries on converted values compare the database value. Keep them simple.

JSON column (Hibernate 6)

@JdbcTypeCode(SqlTypes.JSON)
@Column(columnDefinition = "jsonb")
private Map<String, Object> attributes = new HashMap<>();

@JdbcTypeCode(SqlTypes.JSON)
private ShippingInfo shipping;                                   // any Jackson-serializable class or record
// query: select p from Product p where function('jsonb_extract_path_text', p.attributes, 'color') = 'red'   (or a native query)

Readable timestamps without writing code

@CreationTimestamp @Column(updatable = false) private Instant createdAt;      // Hibernate sets it on insert
@UpdateTimestamp private Instant updatedAt;                                     // Hibernate sets it on every update
// Spring Data alternative with @CreatedDate / @LastModifiedDate needs @EnableJpaAuditing (see the auditing page)

Entity lifecycle callbacks

@PrePersist  void onCreate() { if (sku == null) sku = "SKU-" + UUID.randomUUID(); }
@PreUpdate   void onUpdate() { this.updatedAt = Instant.now(); }
@PostLoad    void afterLoad() { this.priceWithTax = price.multiply(new BigDecimal("1.18")); }
@PreRemove   void beforeDelete() { }
// Callbacks run inside the flush. Do not call repositories or start queries from them.
AnnotationPurpose
@Table(name, schema, uniqueConstraints, indexes)Table name, constraints and indexes (used by schema generation)
@Column(nullable, length, precision, scale, unique, updatable, insertable)Column details
@TransientNot persistent
@LobLarge object
@EnumeratedSTRING or ORDINAL
@ConvertCustom conversion
@Basic(fetch = LAZY)Lazy basic attribute (needs bytecode enhancement)
@AccessField or property access

Common mistake: Using EnumType.ORDINAL (the default!) or double for money. Inserting a new enum constant in the middle silently changes the meaning of existing rows, and double produces rounding errors. Use EnumType.STRING and BigDecimal.

Interview questions

Can a Java record be an entity?

No. Entities need a no-arg constructor, non-final classes and mutable fields for Hibernate. Use records for DTOs and projections. (Records can be @Embeddable in Hibernate 6.2 and newer.)

Why should entities not be final?

Hibernate creates lazy proxies as subclasses of your entity. A final class cannot be extended, so lazy loading of that entity would not work.

Field access or property access?

Field access (@Id on a field). It does not force public getters, and Hibernate does not call your getters and setters (which may contain logic).
