Custom Repositories, Base Class, Domain Events and Auditing

When generated methods are not enough, extend repositories with your own code: fragments for one repository, a custom base class for all, domain events published from aggregates, and auditing fields filled automatically.

Three levels of customization

NeedSolution
Extra method for one repositoryCustom fragment interface + Impl class
Extra method for ALL repositoriesCustom base class with repositoryBaseClass
Change save/delete logic for allOverride in the custom base class
React to changes (events)AbstractAggregateRoot / @DomainEvents, or JPA entity listeners
created/updated who and whenSpring Data auditing

Fragment for one repository

public interface ProductRepositoryCustom {
    List<Product> findLowStock(int threshold);
    int applyDiscount(String category, BigDecimal percent);
}

public class ProductRepositoryCustomImpl implements ProductRepositoryCustom {     // name: fragment interface + "Impl"

    @PersistenceContext private EntityManager em;

    @Override
    public List<Product> findLowStock(int threshold) {
        return em.createQuery("select p from Product p where p.stock < :t order by p.stock", Product.class)
                 .setParameter("t", threshold).getResultList();
    }

    @Override @Transactional
    public int applyDiscount(String category, BigDecimal percent) {
        return em.createQuery("update Product p set p.price = p.price * :f where p.category = :c")
                 .setParameter("f", BigDecimal.ONE.subtract(percent.movePointLeft(2))).setParameter("c", category).executeUpdate();
    }
}

public interface ProductRepository extends JpaRepository<Product, Long>, ProductRepositoryCustom { }

Custom base class for all repositories

@NoRepositoryBean
public interface ShopRepository<T, ID> extends JpaRepository<T, ID> {
    void refresh(T entity);
    List<T> findAllActive();
}

public class ShopRepositoryImpl<T, ID> extends SimpleJpaRepository<T, ID> implements ShopRepository<T, ID> {

    private final EntityManager em;
    private final JpaEntityInformation<T, ?> info;

    public ShopRepositoryImpl(JpaEntityInformation<T, ?> entityInformation, EntityManager entityManager) {
        super(entityInformation, entityManager);
        this.em = entityManager; this.info = entityInformation;
    }

    @Override @Transactional public void refresh(T entity) { em.refresh(entity); }

    @Override
    public List<T> findAllActive() {
        return em.createQuery("select e from " + info.getEntityName() + " e where e.active = true", info.getJavaType()).getResultList();
    }
}

@EnableJpaRepositories(basePackages = "com.example", repositoryBaseClass = ShopRepositoryImpl.class)
class RepoConfig { }

public interface ProductRepository extends ShopRepository<Product, Long> { }      // now has refresh and findAllActive

Auditing: who and when

@Configuration
@EnableJpaAuditing(auditorAwareRef = "auditorProvider", dateTimeProviderRef = "utcNow")
class AuditConfig {
    @Bean AuditorAware<String> auditorProvider() {
        return () -> Optional.ofNullable(SecurityContextHolder.getContext().getAuthentication())
                .filter(Authentication::isAuthenticated).map(Authentication::getName).or(() -> Optional.of("system"));
    }
    @Bean DateTimeProvider utcNow() { return () -> Optional.of(Instant.now()); }
}

@MappedSuperclass
@EntityListeners(AuditingEntityListener.class)
public abstract class Auditable {
    @CreatedDate @Column(updatable = false) private Instant createdAt;
    @LastModifiedDate private Instant updatedAt;
    @CreatedBy @Column(updatable = false) private String createdBy;
    @LastModifiedBy private String updatedBy;
}
// Filled inside the flush by the AuditingEntityListener (a JPA @PrePersist/@PreUpdate callback). Bulk @Modifying queries do NOT trigger it.

Domain events from aggregates

@Entity
public class OrderEntity extends AbstractAggregateRoot<OrderEntity> {

    @Id @GeneratedValue private Long id;
    private OrderStatus status = OrderStatus.NEW;

    public OrderEntity pay() {
        this.status = OrderStatus.PAID;
        registerEvent(new OrderPaid(id));            // collected in the entity, published when repository.save(order) is called
        return this;
    }
}

@Component
class InvoiceListener {
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)      // only after a successful commit
    void on(OrderPaid event) { /* create invoice, send message */ }
}
// Only save(), saveAll(), delete() publish the events. Changes made by dirty checking without save() do NOT publish.

JPA entity listeners and callbacks

public class SearchIndexListener {
    @PostPersist @PostUpdate void index(Object entity) { /* schedule indexing */ }
    @PostRemove void remove(Object entity) { }
}
@Entity @EntityListeners(SearchIndexListener.class)
public class Product { }
// Callbacks run in the middle of the flush: do not run queries or change other entities there. Publish an event or write an outbox row instead.

Common mistake: Doing real work (calling other repositories, HTTP calls) inside JPA callbacks like @PostPersist. They run during flush, the transaction may still roll back and modifying the persistence context there corrupts the flush. Publish an event and handle it after commit.

Interview questions

Where do I put a method that needs the EntityManager?

In a custom fragment (ProductRepositoryCustomImpl) and inject the EntityManager with @PersistenceContext or constructor injection.

Why are my audit fields not set by bulk updates?

Auditing works through JPA entity callbacks on managed entities. A JPQL update statement bypasses entities, so set the audit columns in the statement.

Why is my domain event not published?

Events registered with AbstractAggregateRoot are published when the repository's save or delete is called. Dirty checking alone does not call them.
