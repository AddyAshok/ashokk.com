Spring Data JPA and Hibernate in Depth

A complete course on Spring Data JPA, JPA and Hibernate for working developers. It explains every concept together with its internal workflow: how the EntityManagerFactory bootstraps, how repository interfaces become proxies, how the persistence context and dirty checking work, when SQL is really executed, how fetching and the N+1 problem happen, how batching and caching work, and how locking and transactions protect your data. Each topic is a separate page with internal workflow diagrams, working code, common mistakes and interview questions. Examples use Java 17 or higher with Spring Boot 3.x and 4.x (Hibernate 6).
