Comparator Improvements in Java 8

Java 8 made sorting much easier with static and default methods on Comparator. You can build a sort rule from a getter and chain more rules on it.

How it works in depth

Comparator is a functional interface with one abstract method, compare(a, b), so lambdas work with it. Java 8 added static factory methods (comparing, comparingInt, naturalOrder, reverseOrder, nullsFirst, nullsLast) and default methods (reversed, thenComparing). Together they let you build complex sort rules in a readable, builder style.

Use comparingInt, comparingLong or comparingDouble to avoid boxing. thenComparing accepts a key extractor or another Comparator. Sorting objects is stable, so elements with equal keys keep their earlier relative order. Remember: reversed() reverses the whole comparator built before it.

Key points

  • Comparator.comparing(keyExtractor): sort by one field.
  • thenComparing(): add a second rule when the first is equal.
  • reversed(): flips the order. naturalOrder() and reverseOrder() are also available.
  • nullsFirst() and nullsLast() handle null values safely.

Real life example

Sorting students by marks, and if marks are equal, by name.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Person> people = Arrays.asList(new Person("Sita", 25), new Person("Ram", 30),
                new Person("Amit", 25), new Person("Neha", 30));
        people.sort(Comparator.comparing(Person::getAge));
        System.out.println(people);
        people.sort(Comparator.comparing(Person::getAge).thenComparing(Person::getName));
        System.out.println(people);
        people.sort(Comparator.comparing(Person::getAge).reversed().thenComparing(Person::getName));
        System.out.println(people);
    }
}

class Person {
    String name; int age;
    Person(String n, int a) { name = n; age = a; }
    String getName() { return name; }
    int getAge() { return age; }
    public String toString() { return name + "(" + age + ")"; }
}

Output:

[Sita(25), Amit(25), Ram(30), Neha(30)]
[Amit(25), Sita(25), Neha(30), Ram(30)]
[Neha(30), Ram(30), Amit(25), Sita(25)]

Example 2: Sort by multiple fields with primitive comparators

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Student> list = Arrays.asList(new Student("Ram", 80, 500), new Student("Sita", 90, 400),
                new Student("Amit", 80, 300), new Student("Neha", 90, 450));
        list.sort(Comparator.comparingInt(Student::getMarks).reversed().thenComparingDouble(Student::getFee));
        System.out.println(list);
        list.sort(Comparator.comparing(Student::getName, Comparator.reverseOrder()));
        System.out.println(list);
        list.sort(Comparator.comparing(Student::getName));
        System.out.println(list);
    }
}

class Student {
    String name; int marks; double fee;
    Student(String n, int m, double f) { name = n; marks = m; fee = f; }
    String getName() { return name; }
    int getMarks() { return marks; }
    double getFee() { return fee; }
    public String toString() { return name; }
}

Output:

[Sita, Neha, Amit, Ram]
[Sita, Ram, Neha, Amit]
[Amit, Neha, Ram, Sita]

Example 3: Sorting strings, numbers and nulls

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> items = Arrays.asList("banana", null, "apple", "cherry");
        items.sort(Comparator.nullsFirst(Comparator.naturalOrder()));
        System.out.println(items);
        items.sort(Comparator.nullsLast(Comparator.reverseOrder()));
        System.out.println(items);
        List<String> words = Arrays.asList("pear", "fig", "banana", "kiwi");
        words.sort(Comparator.comparing(String::length).thenComparing(Comparator.naturalOrder()));
        System.out.println(words);
        System.out.println(Collections.max(words, Comparator.comparing(String::length)));
        System.out.println(words.stream().min(Comparator.comparing(String::length)).get());
    }
}

Output:

[null, apple, banana, cherry]
[cherry, banana, apple, null]
[fig, kiwi, pear, banana]
banana
fig

Common mistake: Writing (a, b) -> a.age - b.age by hand. It can overflow for large numbers. Use Comparator.comparing.

Interview questions

What is the difference between comparing and comparingInt?

comparingInt works with an int key and avoids boxing to Integer, so it is faster. Use it when the key is a primitive int.

Does reversed() reverse only the last rule?

No. It reverses the whole comparator it is called on. To reverse only one rule, pass Comparator.reverseOrder() as the second argument of that comparing or thenComparing call.

What is the difference between Comparable and Comparator?

Comparable is implemented inside the class and defines its natural order (compareTo). Comparator is a separate object that defines any custom order.
