Comparator Improvements in Java 8

Java 8 made sorting much easier with static and default methods on Comparator. You can build a sort rule from a getter and chain more rules on it.

Key points

  • Comparator.comparing(keyExtractor): sort by one field.
  • thenComparing(): add a second rule when the first is equal.
  • reversed(): flips the order. naturalOrder() and reverseOrder() are also available.
  • nullsFirst() and nullsLast() handle null values safely.

Real life example

Sorting students by marks, and if marks are equal, by name.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Person> people = Arrays.asList(new Person("Sita", 25), new Person("Ram", 30),
                new Person("Amit", 25), new Person("Neha", 30));
        people.sort(Comparator.comparing(Person::getAge));
        System.out.println(people);
        people.sort(Comparator.comparing(Person::getAge).thenComparing(Person::getName));
        System.out.println(people);
        people.sort(Comparator.comparing(Person::getAge).reversed().thenComparing(Person::getName));
        System.out.println(people);
    }
}

class Person {
    String name; int age;
    Person(String n, int a) { name = n; age = a; }
    String getName() { return name; }
    int getAge() { return age; }
    public String toString() { return name + "(" + age + ")"; }
}

Output

[Sita(25), Amit(25), Ram(30), Neha(30)]
[Amit(25), Sita(25), Neha(30), Ram(30)]
[Neha(30), Ram(30), Amit(25), Sita(25)]

Common mistake: Writing (a, b) -> a.age - b.age by hand. It can overflow for large numbers. Use Comparator.comparing.
