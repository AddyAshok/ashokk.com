forEach, removeIf and replaceAll in Java 8

Java 8 added new methods to collections. forEach(Consumer) loops over elements (internal iteration). removeIf(Predicate) deletes matching elements. replaceAll(UnaryOperator) changes every element of a List. Map also has forEach with a BiConsumer.

Key points

  • forEach is defined in Iterable, so every collection has it.
  • Map.forEach((key, value) -> ...) loops over entries.
  • removeIf and replaceAll change the list, so it must be modifiable (Arrays.asList lists are fixed-size).
  • A forEach loop cannot use break or continue.

Real life example

Instead of visiting each room yourself, you give the cleaner one instruction and they do it in every room.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> fruits = Arrays.asList("Apple", "Banana", "Mango");
        fruits.forEach(f -> System.out.println("Fruit: " + f));
        Map<String, Integer> marks = new TreeMap<>();
        marks.put("Ram", 80);
        marks.put("Sita", 90);
        marks.forEach((k, v) -> System.out.println(k + " -> " + v));
        List<Integer> nums = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5, 6));
        nums.removeIf(n -> n % 2 == 0);
        nums.replaceAll(n -> n * 10);
        System.out.println(nums);
    }
}

Output

Fruit: Apple
Fruit: Banana
Fruit: Mango
Ram -> 80
Sita -> 90
[10, 30, 50]

Common mistake: Calling removeIf on Arrays.asList() or List.of(). It throws UnsupportedOperationException. Wrap the list in new ArrayList<>().
