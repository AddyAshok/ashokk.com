forEach, removeIf and replaceAll in Java 8

Java 8 added new methods to collections. forEach(Consumer) loops over elements (internal iteration). removeIf(Predicate) deletes matching elements. replaceAll(UnaryOperator) changes every element of a List. Map also has forEach with a BiConsumer.

How it works in depth

forEach is a default method in Iterable, so Java could add it to every collection without breaking custom classes. It uses internal iteration and runs the Consumer for each element. Do not change the collection structure (add or remove) inside forEach, because that can throw ConcurrentModificationException.

removeIf is a default method of Collection, and replaceAll is a default method of List and Map. For a HashMap the forEach order is the hash order, so use TreeMap for sorted order or LinkedHashMap for insertion order when the order matters.

Key points

  • forEach is defined in Iterable, so every collection has it.
  • Map.forEach((key, value) -> ...) loops over entries.
  • removeIf and replaceAll change the list, so it must be modifiable (Arrays.asList lists are fixed-size).
  • A forEach loop cannot use break or continue.

Real life example

Instead of visiting each room yourself, you give the cleaner one instruction and they do it in every room.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> fruits = Arrays.asList("Apple", "Banana", "Mango");
        fruits.forEach(f -> System.out.println("Fruit: " + f));
        Map<String, Integer> marks = new TreeMap<>();
        marks.put("Ram", 80);
        marks.put("Sita", 90);
        marks.forEach((k, v) -> System.out.println(k + " -> " + v));
        List<Integer> nums = new ArrayList<>(Arrays.asList(1, 2, 3, 4, 5, 6));
        nums.removeIf(n -> n % 2 == 0);
        nums.replaceAll(n -> n * 10);
        System.out.println(nums);
    }
}

Output:

Fruit: Apple
Fruit: Banana
Fruit: Mango
Ram -> 80
Sita -> 90
[10, 30, 50]

Example 2: Old loop vs forEach

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> cities = Arrays.asList("Delhi", "Mumbai", "Pune");
        for (String c : cities) {
            System.out.println("Loop: " + c);
        }
        cities.forEach(c -> System.out.println("forEach: " + c));
        cities.forEach(System.out::println);
        cities.stream().filter(c -> c.startsWith("M")).forEach(c -> System.out.println("Filtered: " + c));
    }
}

Output:

Loop: Delhi
Loop: Mumbai
Loop: Pune
forEach: Delhi
forEach: Mumbai
forEach: Pune
Delhi
Mumbai
Pune
Filtered: Mumbai

Example 3: removeIf, replaceAll and Map methods

import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>(Arrays.asList("ram", "sita", "amit", "ravi"));
        names.removeIf(n -> n.startsWith("r"));
        System.out.println(names);
        names.replaceAll(String::toUpperCase);
        System.out.println(names);
        Map<String, Integer> prices = new LinkedHashMap<>();
        prices.put("pen", 10);
        prices.put("book", 100);
        prices.replaceAll((k, v) -> v + 5);
        prices.forEach((k, v) -> System.out.println(k + "=" + v));
        prices.entrySet().removeIf(e -> e.getValue() > 50);
        System.out.println(prices);
    }
}

Output:

[sita, amit]
[SITA, AMIT]
pen=15
book=105
{pen=15}

Common mistake: Calling removeIf on Arrays.asList() or List.of(). It throws UnsupportedOperationException. Wrap the list in new ArrayList<>().

Interview questions

Can I use break or continue inside forEach?

No. The lambda is a method, so break and continue do not work. Use a normal for loop, or a stream with limit or anyMatch.

What is the difference between a for loop and forEach?

A for loop is external iteration: you control the loop. forEach is internal iteration: the collection controls it. forEach is shorter, but the normal loop allows break, continue and changing local variables.

What is internal iteration?

The library runs the loop and you only give the action. This lets Java optimize the loop, for example run it in parallel.
