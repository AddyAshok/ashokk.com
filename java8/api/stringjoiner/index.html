StringJoiner and String.join in Java 8

StringJoiner builds a string from many parts with a delimiter, and an optional prefix and suffix. String.join is a quick one-line version.

How it works in depth

StringJoiner is a small helper class in java.util. It collects the parts and joins them when toString() is called. The prefix and suffix are added only once. String.join(delimiter, ...) uses StringJoiner internally and covers the most common case in one line.

Compare with other tools: StringBuilder is more flexible, but you must handle the last delimiter yourself. Collectors.joining is the stream version. merge(otherJoiner) adds the content of another StringJoiner (without its prefix and suffix) as one element.

Key points

  • new StringJoiner(delimiter, prefix, suffix), then add() for each part.
  • setEmptyValue() gives a text to show when nothing was added.
  • String.join(delimiter, items) works with varargs and any Iterable.
  • Collectors.joining() does the same job inside streams.

Real life example

Writing names with commas between them and brackets around the list.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;

public class Main {
    public static void main(String[] args) {
        StringJoiner sj = new StringJoiner(", ", "[", "]");
        sj.add("Ram").add("Sita").add("Amit");
        System.out.println(sj);
        System.out.println(String.join("-", "2024", "03", "15"));
        System.out.println(String.join("/", Arrays.asList("a", "b", "c")));
        StringJoiner empty = new StringJoiner(",", "{", "}");
        empty.setEmptyValue("NONE");
        System.out.println(empty);
        System.out.println(sj.length());
    }
}

Output:

[Ram, Sita, Amit]
2024-03-15
a/b/c
NONE
17

Example 2: Building a list without an extra comma

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        String[] items = {"milk", "eggs", "bread"};
        StringBuilder sb = new StringBuilder();
        for (String i : items) sb.append(i).append(", ");
        System.out.println("StringBuilder: " + sb);
        StringJoiner sj = new StringJoiner(", ");
        for (String i : items) sj.add(i);
        System.out.println("StringJoiner: " + sj);
        System.out.println("String.join: " + String.join(", ", items));
        System.out.println("Stream: " + Arrays.stream(items).collect(Collectors.joining(", ", "<", ">")));
    }
}

Output:

StringBuilder: milk, eggs, bread, 
StringJoiner: milk, eggs, bread
String.join: milk, eggs, bread
Stream: <milk, eggs, bread>

Example 3: merge and empty value

import java.util.*;

public class Main {
    public static void main(String[] args) {
        StringJoiner a = new StringJoiner("-", "(", ")");
        a.add("1").add("2");
        StringJoiner b = new StringJoiner("+", "{", "}");
        b.add("x").add("y");
        a.merge(b);
        System.out.println(a);
        StringJoiner none = new StringJoiner(",", "[", "]");
        System.out.println(none);
        none.setEmptyValue("empty");
        System.out.println(none);
        none.add("");
        System.out.println(none + "|" + none.length());
    }
}

Output:

(1-2-x+y)
[]
empty
[]|2

Common mistake: Building such strings with += in a loop. It creates many temporary objects and leaves an extra delimiter at the end.

Interview questions

When should I use StringJoiner instead of StringBuilder?

Use StringJoiner when you join items with a delimiter, because it handles the last delimiter for you. Use StringBuilder for general text building.

What does String.join do with null elements?

A null element is written as the text null. String.join does not throw an exception for it.

Is StringJoiner thread-safe?

No. Use it only inside one thread, or protect it yourself.
