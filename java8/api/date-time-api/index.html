Date and Time API in Java 8

Java 8 added the java.time package. The old Date and Calendar classes were mutable, not thread-safe and confusing (months started at 0). The new classes are immutable, thread-safe and clear.

How it works in depth

The old java.util.Date is a moment in time that pretends to be a date, is mutable and is not thread-safe. SimpleDateFormat is not thread-safe either. The java.time package follows ISO-8601, is immutable, is thread-safe, and clearly separates human time (LocalDate, LocalTime) from machine time (Instant).

Choose the class by need: LocalDate for a birthday, LocalTime for an opening time, LocalDateTime for an appointment without a time zone, ZonedDateTime for a meeting across time zones, and Instant for a timestamp. ChronoUnit and TemporalAdjusters make date calculations easy, and DateTimeFormatter is immutable and thread-safe.

Key points

  • LocalDate (date), LocalTime (time), LocalDateTime (both), ZonedDateTime (with time zone), Instant (machine time).
  • Period measures days, months and years. Duration measures hours, minutes and seconds.
  • DateTimeFormatter formats and parses text.
  • Every change like plusDays() returns a new object. The original stays the same.

Real life example

A calendar and a clock that never get scribbled on. Every change gives you a fresh copy.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.time.*;
import java.time.format.*;

public class Main {
    public static void main(String[] args) {
        LocalDate date = LocalDate.of(2024, 3, 15);
        System.out.println(date);
        System.out.println(date.plusDays(20));
        System.out.println(date.getDayOfWeek());
        System.out.println(date.isLeapYear());
        LocalTime time = LocalTime.of(14, 30);
        LocalDateTime dt = LocalDateTime.of(date, time);
        System.out.println(dt.format(DateTimeFormatter.ofPattern("dd-MM-yyyy HH:mm")));
        Period p = Period.between(LocalDate.of(2000, 1, 1), date);
        System.out.println(p.getYears() + " years, " + p.getMonths() + " months");
        Duration d = Duration.between(LocalTime.of(9, 0), time);
        System.out.println(d.toMinutes() + " minutes");
        System.out.println(LocalDate.parse("2025-01-01").getMonth());
    }
}

Output:

2024-03-15
2024-04-04
FRIDAY
true
15-03-2024 14:30
24 years, 2 months
330 minutes
JANUARY

Example 2: Date calculations with ChronoUnit and TemporalAdjusters

import java.time.*;
import java.time.format.*;
import java.time.temporal.*;

public class Main {
    public static void main(String[] args) {
        LocalDate start = LocalDate.of(2024, 1, 31);
        System.out.println(start.plusMonths(1));
        System.out.println(ChronoUnit.DAYS.between(start, LocalDate.of(2024, 12, 25)));
        System.out.println(start.with(TemporalAdjusters.firstDayOfNextMonth()));
        System.out.println(start.with(TemporalAdjusters.next(DayOfWeek.MONDAY)));
        System.out.println(start.isBefore(LocalDate.of(2024, 2, 1)));
        System.out.println(start.lengthOfMonth());
        System.out.println(start.withDayOfMonth(1).getDayOfWeek());
    }
}

Output:

2024-02-29
329
2024-02-01
2024-02-05
true
31
MONDAY

Example 3: Time zones and formatting

import java.util.*;
import java.time.*;
import java.time.format.*;

public class Main {
    public static void main(String[] args) {
        LocalDateTime meeting = LocalDateTime.of(2024, 6, 10, 18, 30);
        ZonedDateTime india = meeting.atZone(ZoneId.of("Asia/Kolkata"));
        ZonedDateTime london = india.withZoneSameInstant(ZoneId.of("Europe/London"));
        DateTimeFormatter fmt = DateTimeFormatter.ofPattern("dd MMM yyyy, hh:mm a", Locale.ENGLISH);
        System.out.println(india.format(fmt) + " in India");
        System.out.println(london.format(fmt) + " in London");
        System.out.println(LocalDate.parse("15/08/2024", DateTimeFormatter.ofPattern("dd/MM/yyyy")));
        System.out.println(Instant.ofEpochSecond(0));
    }
}

Output:

10 Jun 2024, 06:30 PM in India
10 Jun 2024, 02:00 PM in London
2024-08-15
1970-01-01T00:00:00Z

Common mistake: Ignoring that objects are immutable. date.plusDays(5) alone does nothing; you must use the returned value.

Interview questions

Why is java.time better than Date and Calendar?

Its classes are immutable and thread-safe, months start at 1, the API is clear, and it separates date, time and zone properly.

What is the difference between LocalDateTime and ZonedDateTime?

LocalDateTime has no time zone, so it is not a fixed moment in time. ZonedDateTime includes a zone and represents an exact moment.

What is the difference between Period and Duration?

Period measures date-based amounts (years, months, days). Duration measures time-based amounts (hours, minutes, seconds, nanoseconds).
