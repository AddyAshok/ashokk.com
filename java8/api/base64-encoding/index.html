Base64 Encoding in Java 8

Java 8 added java.util.Base64 for encoding binary data as text and decoding it back. It is used in emails, URLs, tokens and JSON. Base64 is encoding, not encryption, so it gives no security.

Key points

  • Basic: getEncoder() and getDecoder().
  • URL and filename safe: getUrlEncoder() and getUrlDecoder().
  • MIME: getMimeEncoder() breaks long output into lines.
  • withoutPadding() removes the trailing = characters.

Real life example

Packing a fragile item in a standard box so it can travel through the post safely. Anyone can open the box.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;
import java.nio.charset.StandardCharsets;

public class Main {
    public static void main(String[] args) {
        String original = "Java 8 is great!";
        String encoded = Base64.getEncoder().encodeToString(original.getBytes(StandardCharsets.UTF_8));
        System.out.println(encoded);
        String decoded = new String(Base64.getDecoder().decode(encoded), StandardCharsets.UTF_8);
        System.out.println(decoded);
        String url = Base64.getUrlEncoder().withoutPadding().encodeToString("a?b&c=d>".getBytes(StandardCharsets.UTF_8));
        System.out.println(url);
    }
}

Output

SmF2YSA4IGlzIGdyZWF0IQ==
Java 8 is great!
YT9iJmM9ZD4

Common mistake: Storing passwords with Base64 and thinking they are protected. Anyone can decode it in one line.
