CompletableFuture in Java 8

CompletableFuture is an improved Future. It runs tasks asynchronously and lets you chain, combine and handle errors without blocking. The plain Future could only wait with get().

How it works in depth

A CompletableFuture is both a Future and a CompletionStage. Async tasks run in ForkJoinPool.commonPool() by default, but you can pass your own Executor as the last argument. Methods that end with Async run the next step in another thread; the others run in the thread that finished the previous step.

Chaining methods: thenApply (transform), thenAccept (consume), thenRun (run code), thenCompose (next step returns a future), thenCombine (join two futures). Error handling: exceptionally (recover), handle (result or error) and whenComplete (observe). join() throws an unchecked CompletionException, while get() throws checked exceptions.

Key points

  • supplyAsync(supplier) starts a task in another thread. runAsync is for tasks with no result.
  • thenApply, thenAccept, thenCompose: continue after the task finishes.
  • thenCombine joins two independent futures. allOf and anyOf wait for many futures.
  • exceptionally and handle deal with errors. join() waits for the result.

Real life example

Ordering food and a cake at different shops at the same time, then combining them for the party.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) {
        CompletableFuture<String> f = CompletableFuture.supplyAsync(() -> "Hello")
                .thenApply(s -> s + " World");
        System.out.println(f.join());
        CompletableFuture<Integer> a = CompletableFuture.supplyAsync(() -> 10);
        CompletableFuture<Integer> b = CompletableFuture.supplyAsync(() -> 20);
        System.out.println(a.thenCombine(b, (x, y) -> x + y).join());
        CompletableFuture<Integer> bad = CompletableFuture.supplyAsync(() -> {
            if (true) throw new RuntimeException("boom");
            return 1;
        }).exceptionally(ex -> -1);
        System.out.println(bad.join());
        CompletableFuture.allOf(a, b).join();
        System.out.println("All done");
    }
}

Output:

Hello World
30
-1
All done

Example 2: thenCompose vs thenApply

import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) {
        CompletableFuture<Integer> userId = CompletableFuture.supplyAsync(() -> 7);
        CompletableFuture<String> name = userId.thenCompose(id -> CompletableFuture.supplyAsync(() -> "User-" + id));
        System.out.println(name.join());
        CompletableFuture<CompletableFuture<String>> nested = userId.thenApply(id -> CompletableFuture.supplyAsync(() -> "User-" + id));
        System.out.println(nested.join().join());
        CompletableFuture<Void> done = userId.thenAccept(id -> System.out.println("Got id " + id));
        done.join();
        CompletableFuture<String> combined = name.thenCombine(CompletableFuture.supplyAsync(() -> "Delhi"), (n, c) -> n + " from " + c);
        System.out.println(combined.join());
    }
}

Output:

User-7
User-7
Got id 7
User-7 from Delhi

Example 3: Custom executor, handle and allOf

import java.util.*;
import java.util.stream.*;
import java.util.concurrent.*;

public class Main {
    public static void main(String[] args) {
        ExecutorService pool = Executors.newFixedThreadPool(3);
        List<CompletableFuture<Integer>> futures = new ArrayList<>();
        for (int i = 1; i <= 3; i++) {
            final int n = i;
            futures.add(CompletableFuture.supplyAsync(() -> n * n, pool));
        }
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
        System.out.println(futures.stream().map(CompletableFuture::join).collect(Collectors.toList()));
        CompletableFuture<String> risky = CompletableFuture.supplyAsync(() -> {
            if (true) throw new IllegalStateException("failed");
            return "ok";
        }, pool).handle((result, error) -> {
            if (error == null) return result;
            Throwable root = error.getCause() != null ? error.getCause() : error;
            return "Recovered from: " + root.getMessage();
        });
        System.out.println(risky.join());
        pool.shutdown();
    }
}

Output:

[1, 4, 9]
Recovered from: failed

Common mistake: Calling get() or join() right away on every future. It blocks the thread and cancels the benefit of async code.

Interview questions

What is the difference between Future and CompletableFuture?

Future can only be waited on with a blocking get(). CompletableFuture lets you chain, combine and handle errors without blocking, and you can complete it manually.

What is the difference between join() and get()?

Both wait for the result. get() throws checked exceptions (InterruptedException, ExecutionException). join() throws the unchecked CompletionException, so it is easier to use in lambdas.

Which thread pool does CompletableFuture use?

By default the common ForkJoinPool. For blocking or I/O tasks, pass your own Executor to avoid blocking the shared pool.
