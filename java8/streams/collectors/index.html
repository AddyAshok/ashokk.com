Collectors in Java 8

The Collectors class gives ready-made recipes for the collect() terminal operation. You can gather elements into a list, set or map, join them into a string, group them, count them and calculate averages.

How it works in depth

collect(Collector) is a mutable reduction. A Collector has four parts: a supplier (creates the container), an accumulator (adds one element), a combiner (merges containers in parallel) and a finisher (final conversion). You rarely write your own, because the Collectors class has ready-made ones.

Downstream collectors are collectors used inside groupingBy. groupingBy(classifier, downstream) applies the second collector (counting, summingInt, mapping, maxBy) to every group. By default it returns a HashMap; pass TreeMap::new to get sorted keys. partitioningBy always gives exactly two keys: false and true.

Key points

  • toList(), toSet(), toMap(): collect into collections.
  • joining(delimiter, prefix, suffix): joins strings.
  • groupingBy(classifier, downstream): groups like SQL GROUP BY. partitioningBy(predicate): splits into true and false groups.
  • counting(), summingInt(), averagingInt(), mapping(): downstream collectors used inside grouping.

Real life example

Sorting mail into boxes by city, then counting how many letters are in each box.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Employee> list = Arrays.asList(
            new Employee("Ram", "IT", 50000), new Employee("Sita", "HR", 40000),
            new Employee("Amit", "IT", 60000), new Employee("Neha", "HR", 45000));
        System.out.println(list.stream().map(Employee::getName).collect(Collectors.joining(", ", "[", "]")));
        Map<String, List<String>> byDept = list.stream().collect(Collectors.groupingBy(
                Employee::getDept, TreeMap::new, Collectors.mapping(Employee::getName, Collectors.toList())));
        System.out.println(byDept);
        Map<String, Long> countByDept = list.stream().collect(
                Collectors.groupingBy(Employee::getDept, TreeMap::new, Collectors.counting()));
        System.out.println(countByDept);
        System.out.println(list.stream().collect(Collectors.averagingInt(Employee::getSalary)));
        System.out.println(list.stream().collect(Collectors.partitioningBy(e -> e.getSalary() >= 50000, Collectors.counting())));
    }
}

class Employee {
    String name; String dept; int salary;
    Employee(String n, String d, int s) { name = n; dept = d; salary = s; }
    String getName() { return name; }
    String getDept() { return dept; }
    int getSalary() { return salary; }
}

Output:

[Ram, Sita, Amit, Neha]
{HR=[Sita, Neha], IT=[Ram, Amit]}
{HR=2, IT=2}
48750.0
{false=2, true=2}

Example 2: toSet, toMap and statistics

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> words = Arrays.asList("apple", "bat", "apple", "cat");
        System.out.println(words.stream().collect(Collectors.toSet()).size());
        Map<String, Integer> lengths = words.stream().distinct().collect(Collectors.toMap(w -> w, String::length));
        System.out.println(new TreeMap<>(lengths));
        Map<String, Integer> counts = words.stream().collect(Collectors.toMap(w -> w, w -> 1, Integer::sum));
        System.out.println(new TreeMap<>(counts));
        System.out.println(words.stream().collect(Collectors.summarizingInt(String::length)).getMax());
        List<String> frozen = words.stream().collect(Collectors.collectingAndThen(Collectors.toList(), Collections::unmodifiableList));
        System.out.println(frozen);
    }
}

Output:

3
{apple=5, bat=3, cat=3}
{apple=2, bat=1, cat=1}
5
[apple, bat, apple, cat]

Example 3: Grouping employees with downstream collectors

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Emp> emps = Arrays.asList(new Emp("Ram", "IT", 50000), new Emp("Sita", "HR", 40000),
                new Emp("Amit", "IT", 60000), new Emp("Neha", "HR", 45000), new Emp("Raj", "OPS", 30000));
        Map<String, Integer> total = emps.stream().collect(
                Collectors.groupingBy(Emp::getDept, TreeMap::new, Collectors.summingInt(Emp::getSalary)));
        System.out.println(total);
        Map<String, Optional<Emp>> top = emps.stream().collect(
                Collectors.groupingBy(Emp::getDept, TreeMap::new, Collectors.maxBy(Comparator.comparingInt(Emp::getSalary))));
        top.forEach((d, e) -> System.out.println(d + " top earner: " + e.get().getName()));
        Map<Boolean, List<String>> split = emps.stream().collect(Collectors.partitioningBy(
                e -> e.getSalary() > 42000, Collectors.mapping(Emp::getName, Collectors.toList())));
        System.out.println(split);
    }
}

class Emp {
    String name; String dept; int salary;
    Emp(String n, String d, int s) { name = n; dept = d; salary = s; }
    String getName() { return name; }
    String getDept() { return dept; }
    int getSalary() { return salary; }
}

Output:

{HR=85000, IT=110000, OPS=30000}
HR top earner: Neha
IT top earner: Amit
OPS top earner: Raj
{false=[Sita, Raj], true=[Ram, Amit, Neha]}

Common mistake: toMap() throws IllegalStateException on duplicate keys. Pass a merge function as the third argument.

Interview questions

What is the difference between groupingBy and partitioningBy?

groupingBy makes any number of groups by a key function. partitioningBy uses a Predicate and always makes exactly two groups, false and true.

What happens when toMap finds a duplicate key?

It throws IllegalStateException. Give a merge function as the third argument, for example Integer::sum, to combine the values.

Which List does Collectors.toList() return?

An ArrayList in practice, but the specification gives no guarantee. Use toCollection(LinkedList::new) if you need a specific type.
