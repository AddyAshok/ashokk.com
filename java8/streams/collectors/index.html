Collectors in Java 8

The Collectors class gives ready-made recipes for the collect() terminal operation. You can gather elements into a list, set or map, join them into a string, group them, count them and calculate averages.

Key points

  • toList(), toSet(), toMap(): collect into collections.
  • joining(delimiter, prefix, suffix): joins strings.
  • groupingBy(classifier, downstream): groups like SQL GROUP BY. partitioningBy(predicate): splits into true and false groups.
  • counting(), summingInt(), averagingInt(), mapping(): downstream collectors used inside grouping.

Real life example

Sorting mail into boxes by city, then counting how many letters are in each box.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Employee> list = Arrays.asList(
            new Employee("Ram", "IT", 50000), new Employee("Sita", "HR", 40000),
            new Employee("Amit", "IT", 60000), new Employee("Neha", "HR", 45000));
        System.out.println(list.stream().map(Employee::getName).collect(Collectors.joining(", ", "[", "]")));
        Map<String, List<String>> byDept = list.stream().collect(Collectors.groupingBy(
                Employee::getDept, TreeMap::new, Collectors.mapping(Employee::getName, Collectors.toList())));
        System.out.println(byDept);
        Map<String, Long> countByDept = list.stream().collect(
                Collectors.groupingBy(Employee::getDept, TreeMap::new, Collectors.counting()));
        System.out.println(countByDept);
        System.out.println(list.stream().collect(Collectors.averagingInt(Employee::getSalary)));
        System.out.println(list.stream().collect(Collectors.partitioningBy(e -> e.getSalary() >= 50000, Collectors.counting())));
    }
}

class Employee {
    String name; String dept; int salary;
    Employee(String n, String d, int s) { name = n; dept = d; salary = s; }
    String getName() { return name; }
    String getDept() { return dept; }
    int getSalary() { return salary; }
}

Output

[Ram, Sita, Amit, Neha]
{HR=[Sita, Neha], IT=[Ram, Amit]}
{HR=2, IT=2}
48750.0
{false=2, true=2}

Common mistake: toMap() throws IllegalStateException on duplicate keys. Pass a merge function as the third argument.
