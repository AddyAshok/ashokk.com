Terminal Operations in Java 8

A terminal operation starts the pipeline, produces a result (or a side effect) and closes the stream. Only one terminal operation can be used per stream.

How it works in depth

Terminal operations are eager. They return a value (count, reduce), a boolean (anyMatch), an Optional (findFirst, max, min) or nothing (forEach). Short-circuiting terminal operations such as anyMatch and findFirst stop as soon as the answer is known, so they can work even on infinite streams.

reduce has three forms: reduce(BinaryOperator) returns an Optional; reduce(identity, BinaryOperator) returns a value; reduce(identity, accumulator, combiner) is used when the result type is different or for parallel streams. The operation should be associative, because parallel streams may group elements in any way.

Key points

  • reduce(identity, op): combines all elements into one value (sum, product).
  • count(), min(), max(): simple results. min and max return Optional.
  • anyMatch, allMatch, noneMatch: test a condition and return boolean. They stop early when the answer is known (short-circuit).
  • findFirst, findAny, forEach, toArray, collect are other common terminal operations.

Real life example

The last button on the machine. Until you press it, nothing moves.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(4, 9, 2, 7, 5);
        System.out.println(nums.stream().reduce(0, Integer::sum));
        System.out.println(nums.stream().max(Integer::compare).get());
        System.out.println(nums.stream().min(Integer::compare).get());
        System.out.println(nums.stream().count());
        System.out.println(nums.stream().anyMatch(n -> n > 8));
        System.out.println(nums.stream().allMatch(n -> n > 1));
        System.out.println(nums.stream().noneMatch(n -> n > 10));
        System.out.println(nums.stream().filter(n -> n > 5).findFirst().get());
        nums.stream().sorted().forEach(n -> System.out.print(n + " "));
        System.out.println();
        System.out.println(Arrays.toString(nums.stream().mapToInt(Integer::intValue).toArray()));
    }
}

Example 2: reduce in different forms

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(1, 2, 3, 4, 5);
        Optional<Integer> product = nums.stream().reduce((a, b) -> a * b);
        System.out.println(product.get());
        System.out.println(nums.stream().reduce(0, (a, b) -> a + b));
        System.out.println(nums.stream().reduce(Integer.MIN_VALUE, Math::max));
        System.out.println(Stream.of("a", "b", "c").reduce("", (a, b) -> a + b));
        int totalLength = Stream.of("Java", "Stream").reduce(0, (sum, s) -> sum + s.length(), Integer::sum);
        System.out.println(totalLength);
        System.out.println(new ArrayList<Integer>().stream().reduce(Integer::sum).isPresent());
    }
}

Example 3: Short-circuit operations on an infinite stream

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        System.out.println(Stream.iterate(1, n -> n + 1).filter(n -> n % 7 == 0).findFirst().get());
        System.out.println(Stream.iterate(1, n -> n + 1).anyMatch(n -> n * n > 200));
        IntSummaryStatistics st = Stream.iterate(1, n -> n * 2).limit(5).mapToInt(Integer::intValue).summaryStatistics();
        System.out.println(st.getMin() + " " + st.getMax() + " " + st.getSum() + " " + st.getAverage());
        System.out.println(Stream.of("b", "a", "c").sorted().findFirst().orElse("none"));
        System.out.println(Stream.<String>empty().findFirst().orElse("none"));
    }
}

Output:

7
true
1 16 31 6.2
a
none

Common mistake: Calling get() on the Optional from min/max/findFirst when the stream can be empty. Use orElse instead.

Interview questions

What is the difference between findFirst and findAny?

findFirst always returns the first element in encounter order. findAny may return any element, which is faster in parallel streams.

What is the difference between forEach and forEachOrdered?

forEach may process elements in any order on a parallel stream. forEachOrdered keeps the encounter order, but can be slower.

Why do max and min return an Optional?

The stream can be empty, and then there is no maximum or minimum. Optional forces you to handle that case.
