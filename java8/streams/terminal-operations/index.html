Terminal Operations in Java 8

A terminal operation starts the pipeline, produces a result (or a side effect) and closes the stream. Only one terminal operation can be used per stream.

Key points

  • reduce(identity, op): combines all elements into one value (sum, product).
  • count(), min(), max(): simple results. min and max return Optional.
  • anyMatch, allMatch, noneMatch: test a condition and return boolean. They stop early when the answer is known (short-circuit).
  • findFirst, findAny, forEach, toArray, collect are other common terminal operations.

Real life example

The last button on the machine. Until you press it, nothing moves.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> nums = Arrays.asList(4, 9, 2, 7, 5);
        System.out.println(nums.stream().reduce(0, Integer::sum));
        System.out.println(nums.stream().max(Integer::compare).get());
        System.out.println(nums.stream().min(Integer::compare).get());
        System.out.println(nums.stream().count());
        System.out.println(nums.stream().anyMatch(n -> n > 8));
        System.out.println(nums.stream().allMatch(n -> n > 1));
        System.out.println(nums.stream().noneMatch(n -> n > 10));
        System.out.println(nums.stream().filter(n -> n > 5).findFirst().get());
        nums.stream().sorted().forEach(n -> System.out.print(n + " "));
        System.out.println();
        System.out.println(Arrays.toString(nums.stream().mapToInt(Integer::intValue).toArray()));
    }
}
