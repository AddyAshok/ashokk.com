Stream API Basics in Java 8

A stream is a sequence of elements that supports operations such as filter, map and collect. A stream does not store data. It reads data from a source (collection, array), runs a pipeline of operations, and gives a result. A pipeline is: source, then intermediate operations, then one terminal operation.

How it works in depth

Streams use internal iteration: you say what to do and the library decides how to loop. Data flows through the pipeline one element at a time, not stage by stage. For filter followed by map, the first element goes through both steps before the second element starts. This saves memory and allows early stopping.

A collection stores data and can be used many times. A stream is a one-time computation over data and can even be infinite (Stream.iterate). Java also has primitive streams (IntStream, LongStream, DoubleStream) that avoid boxing and offer sum(), average() and range().

Key points

  • Streams never change the original source.
  • Intermediate operations are lazy. Nothing runs until a terminal operation is called.
  • A stream can be used only once. A second use throws IllegalStateException.
  • Create streams with list.stream(), Arrays.stream(array), Stream.of(...), IntStream.range(1, 5), Stream.iterate() and Stream.generate().

Real life example

A factory conveyor belt: items enter, pass through stations (filter, change), and come out as a finished box.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(5, 12, 8, 21, 3, 16);
        List<Integer> result = numbers.stream()        // source
                .filter(n -> n > 5)                    // intermediate
                .map(n -> n * 2)                       // intermediate
                .collect(Collectors.toList());         // terminal
        System.out.println(result);
        System.out.println(numbers);                   // source is unchanged
        System.out.println(IntStream.rangeClosed(1, 5).sum());
        System.out.println(Stream.of("a", "b", "c").count());
        Stream<Integer> s = numbers.stream();
        s.count();
        try { s.count(); } catch (IllegalStateException e) { System.out.println("Stream already used"); }
    }
}

Output:

[24, 16, 42, 32]
[5, 12, 8, 21, 3, 16]
15
3
Stream already used

Example 2: Elements flow one by one (lazy evaluation)

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> result = Stream.of("a", "bb", "ccc", "dd")
                .filter(s -> { System.out.println("filter: " + s); return s.length() > 1; })
                .map(s -> { System.out.println("map: " + s); return s.toUpperCase(); })
                .limit(2)
                .collect(Collectors.toList());
        System.out.println(result);
    }
}

Output:

filter: a
filter: bb
map: bb
filter: ccc
map: ccc
[BB, CCC]

Example 3: Different ways to create streams

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        int[] array = {3, 1, 2};
        System.out.println(Arrays.stream(array).sum());
        System.out.println(Stream.of("x", "y").collect(Collectors.toList()));
        System.out.println(IntStream.range(0, 5).boxed().collect(Collectors.toList()));
        System.out.println(Stream.iterate(1, n -> n * 2).limit(6).collect(Collectors.toList()));
        System.out.println(Stream.generate(() -> "hi").limit(3).collect(Collectors.joining("-")));
        System.out.println(IntStream.of(4, 8, 12).average().getAsDouble());
    }
}

Output:

6
[x, y]
[0, 1, 2, 3, 4]
[1, 2, 4, 8, 16, 32]
hi-hi-hi
8.0

Common mistake: Reusing a stream after a terminal operation. Create a new stream each time.

Interview questions

What is the difference between a Stream and a Collection?

A collection stores data in memory and can be used many times. A stream stores nothing, is used only once and describes a computation on data.

Can a stream be reused?

No. After a terminal operation the stream is closed. Using it again throws IllegalStateException. Create a new stream from the source.

What is a short-circuit operation?

An operation that can finish before it sees all elements, such as limit, findFirst and anyMatch. This lets streams work on infinite data.
