Stream API Basics in Java 8

A stream is a sequence of elements that supports operations such as filter, map and collect. A stream does not store data. It reads data from a source (collection, array), runs a pipeline of operations, and gives a result. A pipeline is: source, then intermediate operations, then one terminal operation.

Key points

  • Streams never change the original source.
  • Intermediate operations are lazy. Nothing runs until a terminal operation is called.
  • A stream can be used only once. A second use throws IllegalStateException.
  • Create streams with list.stream(), Arrays.stream(array), Stream.of(...), IntStream.range(1, 5), Stream.iterate() and Stream.generate().

Real life example

A factory conveyor belt: items enter, pass through stations (filter, change), and come out as a finished box.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> numbers = Arrays.asList(5, 12, 8, 21, 3, 16);
        List<Integer> result = numbers.stream()        // source
                .filter(n -> n > 5)                    // intermediate
                .map(n -> n * 2)                       // intermediate
                .collect(Collectors.toList());         // terminal
        System.out.println(result);
        System.out.println(numbers);                   // source is unchanged
        System.out.println(IntStream.rangeClosed(1, 5).sum());
        System.out.println(Stream.of("a", "b", "c").count());
        Stream<Integer> s = numbers.stream();
        s.count();
        try { s.count(); } catch (IllegalStateException e) { System.out.println("Stream already used"); }
    }
}

Output

[24, 16, 42, 32]
[5, 12, 8, 21, 3, 16]
15
3
Stream already used

Common mistake: Reusing a stream after a terminal operation. Create a new stream each time.
