Intermediate Operations in Java 8

Intermediate operations return a new stream, so you can chain them. They are lazy: they do nothing until a terminal operation starts the pipeline.

How it works in depth

Intermediate operations are either stateless or stateful. filter, map and peek are stateless: each element is handled alone. sorted and distinct are stateful: sorted must see all elements first, and distinct must remember what it has seen. Stateful operations need more memory and can slow down parallel streams.

map is one-to-one: each input gives exactly one output. flatMap is one-to-many: each input gives a stream, and all those streams are merged into one flat stream. Variants like mapToInt and mapToDouble return primitive streams that avoid boxing.

Key points

  • filter(Predicate): keeps matching elements.
  • map(Function): changes each element. flatMap(Function): turns many small streams into one stream.
  • sorted(), distinct(), limit(n), skip(n): sort, remove duplicates, take first n, skip first n.
  • peek(Consumer): look at elements while they pass, mainly for debugging.

Real life example

Stations on a conveyor belt: one removes bad items, one paints, one sorts.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> words = Arrays.asList("banana", "apple", "cherry", "apple", "date");
        System.out.println(words.stream().filter(w -> w.length() > 4).collect(Collectors.toList()));
        System.out.println(words.stream().map(String::toUpperCase).collect(Collectors.toList()));
        System.out.println(words.stream().distinct().sorted().collect(Collectors.toList()));
        System.out.println(words.stream().skip(1).limit(2).collect(Collectors.toList()));
        List<List<Integer>> nested = Arrays.asList(Arrays.asList(1, 2), Arrays.asList(3, 4), Arrays.asList(5));
        System.out.println(nested.stream().flatMap(List::stream).collect(Collectors.toList()));
        List<String> a = words.stream().filter(w -> w.startsWith("a"))
                .peek(w -> System.out.println("peek: " + w)).collect(Collectors.toList());
        System.out.println(a);
    }
}

Output:

[banana, apple, cherry, apple]
[BANANA, APPLE, CHERRY, APPLE, DATE]
[apple, banana, cherry, date]
[apple, cherry]
[1, 2, 3, 4, 5]
peek: apple
peek: apple
[apple, apple]

Example 2: map vs flatMap

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<String> sentences = Arrays.asList("Java is fun", "Streams are powerful");
        System.out.println(sentences.stream().map(s -> s.split(" ")).count());
        System.out.println(sentences.stream().flatMap(s -> Arrays.stream(s.split(" "))).count());
        System.out.println(sentences.stream().flatMap(s -> Arrays.stream(s.split(" "))).map(String::length).collect(Collectors.toList()));
        System.out.println(sentences.stream().mapToInt(String::length).sum());
    }
}

Output:

2
6
[4, 2, 3, 7, 3, 8]
31

Example 3: Sorting objects and pagination with skip and limit

import java.util.*;
import java.util.stream.*;

public class Main {
    public static void main(String[] args) {
        List<Product> products = Arrays.asList(new Product("Pen", 10), new Product("Book", 250),
                new Product("Bag", 900), new Product("Lamp", 450), new Product("Cup", 120));
        System.out.println(products.stream().sorted(Comparator.comparing(Product::getPrice).reversed())
                .map(Product::getName).collect(Collectors.toList()));
        int page = 2, size = 2;
        System.out.println(products.stream().map(Product::getName).skip((page - 1) * size).limit(size).collect(Collectors.toList()));
        System.out.println(products.stream().filter(p -> p.getPrice() > 100).map(Product::getName).sorted().collect(Collectors.toList()));
    }
}

class Product {
    String name; double price;
    Product(String n, double p) { name = n; price = p; }
    String getName() { return name; }
    double getPrice() { return price; }
}

Output:

[Bag, Lamp, Book, Cup, Pen]
[Bag, Lamp]
[Bag, Book, Cup, Lamp]

Common mistake: Using peek() to change data or expecting it to run without a terminal operation.

Interview questions

What is the difference between map and flatMap?

map converts each element into exactly one new element. flatMap converts each element into a stream and joins all streams into one, so it is used for nested lists or splitting text.

Is sorted() stable?

Yes, for ordered streams. Elements that compare as equal keep their original relative order.

Why does my peek() print nothing?

Intermediate operations are lazy. Without a terminal operation such as collect or count, the pipeline never runs.
