Default and Static Methods in Interfaces in Java 8

Before Java 8 an interface could only have abstract methods, so adding a new method broke every class that implemented it. Java 8 allows default methods (with a body) and static methods in interfaces. This is how Java added stream() and forEach() to Collection without breaking old code.

How it works in depth

Default methods were added for backward compatibility. If forEach() had been added to Iterable as an abstract method, millions of classes would have stopped compiling. As a default method, every old class got it for free. Conflict rules: a method from a class always wins over an interface; a more specific interface wins over a general one; otherwise the class must override the method.

Static interface methods are utility methods that belong to the interface itself, for example Comparator.naturalOrder() and Stream.of(). They cannot be overridden and are not inherited by implementing classes. Private interface methods were added later in Java 9, not in Java 8.

Key points

  • A default method uses the default keyword. Implementing classes may override it.
  • If a class implements two interfaces with the same default method, it must override it and can call Interface.super.method().
  • A static method belongs to the interface. Call it as InterfaceName.method(); it is not inherited.
  • Interfaces still cannot have instance fields or constructors.

Real life example

A company adds a new rule to its handbook. Old employees follow a default version until they choose their own.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

public class Main {
    public static void main(String[] args) {
        new Tesla().start();
        System.out.println(Vehicle.wheels());
    }
}

interface Vehicle {
    default void start() { System.out.println("Vehicle starting"); }
    static int wheels() { return 4; }
}

interface Electric {
    default void start() { System.out.println("Electric starting"); }
}

class Tesla implements Vehicle, Electric {
    public void start() {                      // must resolve the conflict
        Vehicle.super.start();
        Electric.super.start();
    }
}

Output:

Vehicle starting
Electric starting
4

Example 2: Adding a method without breaking old classes

public class Main {
    public static void main(String[] args) {
        System.out.println(new Square().describe());
        System.out.println(new Circle().describe());
    }
}

interface Shape {
    double area();
    default String describe() { return "Shape with area " + area(); }
}

class Square implements Shape {
    double side = 3;
    public double area() { return side * side; }
}
class Circle implements Shape {
    double r = 1;
    public double area() { return 3.14 * r * r; }
    public String describe() { return "Circle! " + Shape.super.describe(); }
}

Output:

Shape with area 9.0
Circle! Shape with area 3.14

Example 3: Static helper method and the class-wins rule

public class Main {
    public static void main(String[] args) {
        Validator v = Validator.notEmpty().and(s -> s.length() < 5);
        System.out.println(v.validate("Java"));
        System.out.println(v.validate("Programming"));
        System.out.println(v.validate(""));
        System.out.println(new Child().hello());
    }
}

interface Validator {
    boolean validate(String s);
    static Validator notEmpty() { return s -> s != null && !s.isEmpty(); }
    default Validator and(Validator other) { return s -> validate(s) && other.validate(s); }
}
class Base { public String hello() { return "Hello from class"; } }
interface Greeter { default String hello() { return "Hello from interface"; } }
class Child extends Base implements Greeter { }

Output:

true
false
false
Hello from class

Common mistake: Forgetting to resolve the conflict when two interfaces have the same default method gives a compile error.

Interview questions

How does Java solve the diamond problem?

If two interfaces give the same default method, the class must override it and choose explicitly, for example Vehicle.super.start(). Otherwise the code does not compile.

Can a default method override methods of Object like equals()?

No. A default method cannot override equals(), hashCode() or toString(). It gives a compile error.

What is the difference between an abstract class and an interface now?

An abstract class can have fields (state) and constructors, but an interface cannot. A class can implement many interfaces but extend only one class.
