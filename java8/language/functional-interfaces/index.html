Functional Interfaces in Java 8

A functional interface has exactly one abstract method. It can also have many default and static methods. Lambdas and method references work only with functional interfaces. Java 8 added the @FunctionalInterface annotation and the java.util.function package with ready-made interfaces.

Key points

  • Predicate<T>: takes T, returns boolean (method test).
  • Function<T,R>: takes T, returns R (method apply).
  • Consumer<T>: takes T, returns nothing (method accept). Supplier<T>: takes nothing, returns T (method get).
  • Also available: BiFunction, UnaryOperator, BinaryOperator. Older ones like Runnable and Comparator are functional interfaces too.

Real life example

A power socket that accepts one type of plug. Any device with that plug (any lambda with the right shape) fits.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        Greeting g = name -> "Hello, " + name;
        Predicate<Integer> isEven = n -> n % 2 == 0;
        Function<String, Integer> length = s -> s.length();
        Consumer<String> printer = s -> System.out.println("Consumed: " + s);
        Supplier<Double> pi = () -> 3.14159;
        UnaryOperator<String> upper = String::toUpperCase;
        System.out.println(g.greet("Ram"));
        System.out.println(isEven.test(10));
        System.out.println(isEven.negate().test(10));
        System.out.println(length.apply("Java 8"));
        printer.accept("data");
        System.out.println(pi.get());
        System.out.println(upper.apply("abc"));
    }
}

@FunctionalInterface
interface Greeting {
    String greet(String name);
}

Output

Hello, Ram
true
false
6
Consumed: data
3.14159
ABC

Common mistake: If you add a second abstract method, the interface is no longer functional and lambda assignments stop compiling. @FunctionalInterface makes the compiler warn you early.
