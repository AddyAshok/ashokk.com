Functional Interfaces in Java 8

A functional interface has exactly one abstract method. It can also have many default and static methods. Lambdas and method references work only with functional interfaces. Java 8 added the @FunctionalInterface annotation and the java.util.function package with ready-made interfaces.

How it works in depth

The rule is one abstract method. Methods inherited from Object, such as equals(), do not count, and default or static methods do not count either. That is why Comparator is a functional interface even though it declares equals().

The java.util.function package has 43 interfaces. Primitive versions such as IntPredicate, IntFunction and ToIntFunction avoid boxing and are faster. Versions that take two arguments start with Bi (BiFunction, BiConsumer, BiPredicate). Predicate and Function also have default methods like and(), or(), negate(), andThen() and compose() to build bigger logic from small pieces.

Key points

  • Predicate<T>: takes T, returns boolean (method test).
  • Function<T,R>: takes T, returns R (method apply).
  • Consumer<T>: takes T, returns nothing (method accept). Supplier<T>: takes nothing, returns T (method get).
  • Also available: BiFunction, UnaryOperator, BinaryOperator. Older ones like Runnable and Comparator are functional interfaces too.

Real life example

A power socket that accepts one type of plug. Any device with that plug (any lambda with the right shape) fits.

Example 1: Basics

Save as Main.java, compile with javac Main.java and run with java Main (Java 8 or higher).

import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        Greeting g = name -> "Hello, " + name;
        Predicate<Integer> isEven = n -> n % 2 == 0;
        Function<String, Integer> length = s -> s.length();
        Consumer<String> printer = s -> System.out.println("Consumed: " + s);
        Supplier<Double> pi = () -> 3.14159;
        UnaryOperator<String> upper = String::toUpperCase;
        System.out.println(g.greet("Ram"));
        System.out.println(isEven.test(10));
        System.out.println(isEven.negate().test(10));
        System.out.println(length.apply("Java 8"));
        printer.accept("data");
        System.out.println(pi.get());
        System.out.println(upper.apply("abc"));
    }
}

@FunctionalInterface
interface Greeting {
    String greet(String name);
}

Output:

Hello, Ram
true
false
6
Consumed: data
3.14159
ABC

Example 2: Combining Predicates and Functions

import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        Predicate<String> startsWithA = s -> s.startsWith("A");
        Predicate<String> longWord = s -> s.length() > 4;
        System.out.println(startsWithA.and(longWord).test("Apple"));
        System.out.println(startsWithA.or(longWord).test("Bat"));
        Function<Integer, Integer> doubleIt = x -> x * 2;
        Function<Integer, Integer> plusTen = x -> x + 10;
        System.out.println(doubleIt.andThen(plusTen).apply(5));
        System.out.println(doubleIt.compose(plusTen).apply(5));
        BiFunction<Integer, Integer, Integer> mul = (a, b) -> a * b;
        System.out.println(mul.andThen(x -> x + 1).apply(3, 4));
    }
}

Output:

true
false
20
30
13

Example 3: Primitive functional interfaces

import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        IntPredicate isPositive = n -> n > 0;
        IntBinaryOperator sum = (a, b) -> a + b;
        ToIntFunction<String> lengthOf = String::length;
        IntFunction<String> stars = n -> "*" + n;
        Supplier<String> lazy = () -> "computed later";
        System.out.println(isPositive.test(-5));
        System.out.println(sum.applyAsInt(3, 4));
        System.out.println(lengthOf.applyAsInt("Hello"));
        System.out.println(stars.apply(3));
        System.out.println(lazy.get());
    }
}

Output:

false
7
5
*3
computed later

Common mistake: If you add a second abstract method, the interface is no longer functional and lambda assignments stop compiling. @FunctionalInterface makes the compiler warn you early.

Interview questions

Can a functional interface have default methods?

Yes. It can have any number of default and static methods. Only the abstract method count matters.

Is @FunctionalInterface mandatory?

No. Any interface with one abstract method works with lambdas. The annotation is optional but recommended because the compiler then checks the rule for you.

What is the difference between Predicate and Function?

A Predicate always returns boolean and is used for tests and filters. A Function returns any type and is used for transformations.
