Method References in Java 8

A method reference is a shorter form of a lambda that only calls one existing method. You write it with the :: operator. It makes code shorter and easier to read.

Key points

  • Static method: ClassName::staticMethod (Util::isLong).
  • Method of a specific object: object::method (System.out::println).
  • Method of any object of a type: ClassName::instanceMethod (String::length).
  • Constructor: ClassName::new (ArrayList::new). The method must match the functional interface signature.

Real life example

Instead of writing the whole instruction again, you just point to a method that already does the job.

Complete Java example

Save this as Main.java, then run javac Main.java and java Main (Java 8 or higher).

import java.util.*;
import java.util.function.*;

public class Main {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Ram", "Sita", "Laxman");
        names.forEach(System.out::println);
        Predicate<String> longName = Util::isLong;
        System.out.println(longName.test("Sita"));
        Function<String, Integer> len = String::length;
        System.out.println(len.apply("Java"));
        Supplier<List<String>> maker = ArrayList::new;
        List<String> fresh = maker.get();
        fresh.add("New");
        System.out.println(fresh);
    }
}

class Util {
    static boolean isLong(String s) { return s.length() > 3; }
}

Output

Ram
Sita
Laxman
true
4
[New]

Common mistake: If a method is overloaded, the compiler may not know which one you mean. Use a lambda in that case.
