Java 8 Features in Depth

Java 8 (released in March 2014) is the biggest update in the history of Java. It added lambdas, streams, Optional, a new date and time API and much more. Each feature below has its own page with a clear explanation, key points, a complete program and its output.

Language Features

Java 8 changed how we write Java. These features let you pass code as data and write shorter, cleaner programs.

Lambda ExpressionsA lambda expression is a short way to write an anonymous function.Functional InterfacesA functional interface has exactly one abstract method.Method ReferencesA method reference is a shorter form of a lambda that only calls one existing method.Default and Static Methods in InterfacesBefore Java 8 an interface could only have abstract methods, so adding a new method broke every class that implemented it.

Stream API

The Stream API processes collections in a declarative way: describe what you want, not how to loop. It is one of the biggest additions of Java 8.

Stream API BasicsA stream is a sequence of elements that supports operations such as filter, map and collect.Intermediate OperationsIntermediate operations return a new stream, so you can chain them.Terminal OperationsA terminal operation starts the pipeline, produces a result (or a side effect) and closes the stream.CollectorsThe Collectors class gives ready-made recipes for the collect() terminal operation.Parallel StreamsA parallel stream splits the work across many threads (the ForkJoin common pool) so it can use all CPU cores.

New APIs

Java 8 also brought many useful new classes and methods that make everyday coding easier and safer.

OptionalOptional<T> is a container that may or may not hold a non-null value.Date and Time APIJava 8 added the java.time package.forEach, removeIf and replaceAllJava 8 added new methods to collections.New Methods in MapJava 8 added methods to Map that replace common if-else code: getOrDefault, putIfAbsent, computeIfAbsent, computeIfPresent, compute and merge.Comparator ImprovementsJava 8 made sorting much easier with static and default methods on Comparator.StringJoiner and String.joinStringJoiner builds a string from many parts with a delimiter, and an optional prefix and suffix.Base64 EncodingJava 8 added java.util.Base64 for encoding binary data as text and decoding it back.CompletableFutureCompletableFuture is an improved Future.
