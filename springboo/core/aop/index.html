Aspect-Oriented Programming (AOP)

AOP lets you write cross-cutting code (logging, timing, security, transactions) once, and apply it to many methods without changing them. @Transactional, @Cacheable and @Async are all implemented with AOP.

Terms

TermMeaningExample
AspectA class with cross-cutting logicLoggingAspect
AdviceThe code that runs and when@Before, @After, @Around
Join pointA point in the program where advice can runA method call
PointcutAn expression that selects join pointsexecution(* com.example.service..*(..))
WeavingLinking the aspect with the targetDone at runtime with proxies in Spring

Spring AOP is proxy based. Spring wraps your bean in a proxy (JDK dynamic proxy if there is an interface, otherwise CGLIB subclass). Calls from outside go through the proxy, and the proxy runs the advice before and after your method.

<!-- Boot 3.x dependency (in Boot 4 the starter is spring-boot-starter-aspectj) -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-aop</artifactId>
</dependency>

Logging and timing aspect

import org.aspectj.lang.JoinPoint;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.*;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

@Aspect
@Component
public class LoggingAspect {

    private static final Logger log = LoggerFactory.getLogger(LoggingAspect.class);

    @Pointcut("execution(* com.example.demo.service..*(..))")
    public void serviceMethods() { }

    @Before("serviceMethods()")
    public void before(JoinPoint jp) {
        log.info("Calling {}", jp.getSignature().toShortString());
    }

    @AfterReturning(pointcut = "serviceMethods()", returning = "result")
    public void afterReturning(JoinPoint jp, Object result) {
        log.info("{} returned {}", jp.getSignature().getName(), result);
    }

    @AfterThrowing(pointcut = "serviceMethods()", throwing = "ex")
    public void afterThrowing(JoinPoint jp, Exception ex) {
        log.error("{} failed: {}", jp.getSignature().getName(), ex.getMessage());
    }

    @Around("serviceMethods()")
    public Object time(ProceedingJoinPoint pjp) throws Throwable {
        long start = System.nanoTime();
        try {
            return pjp.proceed();                       // call the real method
        } finally {
            long ms = (System.nanoTime() - start) / 1_000_000;
            log.info("{} took {} ms", pjp.getSignature().getName(), ms);
        }
    }
}

Custom annotation with AOP

@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Audit { String action(); }

@Aspect
@Component
public class AuditAspect {
    @Around("@annotation(audit)")
    public Object audit(ProceedingJoinPoint pjp, Audit audit) throws Throwable {
        System.out.println("AUDIT start: " + audit.action());
        Object result = pjp.proceed();
        System.out.println("AUDIT end: " + audit.action());
        return result;
    }
}

@Service
public class UserService {
    @Audit(action = "DELETE_USER")
    public void deleteUser(Long id) { /* ... */ }
}

Limits of proxy based AOP

  • Self-invocation: if a method calls another method of the same class with this.method(), the proxy is bypassed and the advice does not run.
  • Only calls from outside the bean are intercepted, and only public methods are advised by default.
  • final classes and final methods cannot be proxied with CGLIB.
  • For advice on private methods or self calls, use full AspectJ weaving.

Common mistake: Calling an @Around or @Transactional method from another method in the same class and expecting the aspect to run. The call does not go through the proxy.

Interview questions

What is the difference between @Before, @After and @Around?

@Before runs before the method, @After after it (always), and @Around wraps the call and controls whether and how the method is executed.

Which proxy types does Spring use?

JDK dynamic proxies for beans that implement interfaces, CGLIB subclass proxies otherwise. Spring Boot uses CGLIB by default (spring.aop.proxy-target-class=true).

Where does Spring itself use AOP?

Transactions (@Transactional), caching (@Cacheable), async (@Async), method security (@PreAuthorize) and retry.
