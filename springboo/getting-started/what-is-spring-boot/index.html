What is Spring Boot?

Spring Boot is a framework built on top of the Spring Framework. It lets you create stand-alone, production-ready applications with very little configuration. You write your business code, and Spring Boot sets up the server, the database connection, JSON conversion, logging and much more for you. The latest stable line is Spring Boot 4.1 (June 2026), and it needs Java 17 or higher (Java 21 or higher is recommended).

Spring Framework vs Spring Boot

PointSpring FrameworkSpring Boot
ConfigurationYou write XML or Java configuration for everythingAuto-configuration sets sensible defaults
ServerBuild a WAR and deploy to an external TomcatEmbedded Tomcat inside the jar. Run with java -jar
DependenciesYou choose every library and its versionStarters and a tested version list (BOM)
Setup timeHours or daysMinutes (start.spring.io)
Production toolsYou build themActuator: health, metrics, info out of the box
StyleFlexible, but you configure a lotOpinionated: defaults first, override when needed

Main features

  • Auto-configuration: Spring Boot looks at your classpath and creates the beans you probably need.
  • Starters: one dependency brings a full set of compatible libraries (for example spring-boot-starter-data-jpa).
  • Embedded server: Tomcat by default, Jetty and Undertow are options.
  • Externalized configuration: properties, YAML, environment variables and command line arguments.
  • Actuator: health checks, metrics and monitoring endpoints.
  • No code generation and no XML needed.
  • DevTools: automatic restart while you develop.

There is no LTS version in Spring Boot. A new minor version comes about every six months, and each minor version gets open source support for about 12 months. Always check the Spring Boot support page before choosing a version for a new project.

The smallest Spring Boot application

package com.example.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@SpringBootApplication
@RestController
public class DemoApplication {

    @GetMapping("/hello")
    public String hello() {
        return "Hello from Spring Boot";
    }

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

What happens when you run it

main()  ──►  SpringApplication.run()
                 │
                 ├─ 1. create the ApplicationContext (the bean container)
                 ├─ 2. scan your packages for @Component, @Service, @RestController ...
                 ├─ 3. run auto-configuration (DispatcherServlet, Jackson, DataSource ...)
                 ├─ 4. start the embedded Tomcat on port 8080
                 └─ 5. publish ApplicationReadyEvent  ──►  app is ready

Common mistake: Thinking Spring Boot replaces Spring. It does not. Spring Boot is Spring with automatic setup. All Spring concepts (beans, DI, AOP, transactions) still apply.

Interview questions

Do I need XML configuration in Spring Boot?

No. Spring Boot uses Java annotations and properties or YAML files. XML is still possible but almost never needed.

Which server does Spring Boot use by default?

Embedded Apache Tomcat on port 8080. You can switch to Jetty or Undertow by changing the dependencies.

Is Spring Boot only for microservices?

No. It works for monoliths, REST APIs, web apps, batch jobs and microservices.
