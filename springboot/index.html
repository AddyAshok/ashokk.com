Spring Boot in Depth

A complete Spring Boot course in simple English: from your first project to internals, REST APIs, databases, security, testing and deployment. Every topic has its own page with clear explanations, working code, common mistakes and interview questions. The examples use Java 17 or higher and follow Spring Boot 3.x and 4.x; where the two versions differ, the page tells you.

Getting Started

Understand what Spring Boot is, create a project and learn how auto-configuration and starters work.

What is Spring Boot?Spring Boot is a framework built on top of the Spring Framework.Create Your First Spring Boot ProjectThis page shows how to create a project, what every folder means, how to run it and how to package it.Auto-Configuration InternalsAuto-configuration is the heart of Spring Boot.Starters and Dependency ManagementA starter is a single dependency that pulls in everything you need for one feature, with versions that are tested together.

Core Concepts

The Spring core that every Spring Boot application depends on: beans, injection, configuration and AOP.

IoC Container and Dependency InjectionInversion of Control (IoC) means you do not create your objects with new.Bean Lifecycle and ScopesEvery bean goes through a fixed life: it is created, filled with dependencies, initialized, used and finally destroyed.Configuration, Properties and ProfilesSpring Boot lets you keep configuration outside the code, so the same jar runs in development, test and production.Aspect-Oriented Programming (AOP)AOP lets you write cross-cutting code (logging, timing, security, transactions) once, and apply it to many methods without changing them.

Build REST APIs, validate input, handle errors and call other services.

REST ControllersA REST controller receives HTTP requests, calls your service layer and returns data (usually JSON).Validation and Exception HandlingNever trust input.Spring MVC InternalsWhen a request reaches your controller, many components work behind the scenes.Calling Other APIs: RestClient and WebClientMost applications call other services.

Work with databases using Spring Data JPA, relationships, transactions, pooling and migrations.

Spring Data JPASpring Data JPA removes almost all database boilerplate.JPA Relationships and the N+1 ProblemRelationships connect entities.Transactions with @TransactionalA transaction groups database operations so that they all succeed or all fail together.Connection Pool (HikariCP) and Flyway MigrationsTwo things every real project needs: a tuned connection pool, and versioned database migrations instead of letting Hibernate change your schema.Complete CRUD REST API (All Layers)This page puts everything together: entity, repository, DTOs, service, controller, validation and error handling, in a clean layered structure.
