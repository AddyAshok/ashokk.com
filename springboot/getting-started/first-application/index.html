Create Your First Spring Boot Project

This page shows how to create a project, what every folder means, how to run it and how to package it. You will finish with a working REST endpoint.

Step 1: Generate the project

  • Open start.spring.io (Spring Initializr).
  • Choose Maven or Gradle, Java 21 (or 17), packaging Jar.
  • Add dependencies: Spring Web, Validation, Spring Data JPA, H2 Database, Actuator, DevTools.
  • Click Generate, unzip the file and open it in IntelliJ IDEA, Eclipse or VS Code.

Project structure

demo/
├── pom.xml                              ← dependencies and build plugin
├── mvnw, mvnw.cmd                       ← Maven wrapper (no need to install Maven)
└── src/
    ├── main/
    │   ├── java/com/example/demo/
    │   │   ├── DemoApplication.java     ← main class with @SpringBootApplication
    │   │   ├── controller/              ← REST controllers
    │   │   ├── service/                 ← business logic
    │   │   ├── repository/              ← database access
    │   │   ├── model/ (entity, dto)     ← data classes
    │   │   └── config/                  ← configuration classes
    │   └── resources/
    │       ├── application.properties   ← configuration
    │       ├── static/                  ← css, js, images
    │       └── templates/               ← Thymeleaf pages
    └── test/java/...                    ← tests

Tip: Keep the main class in the root package (com.example.demo). Component scanning starts from that package and includes all sub-packages. A class outside this package is not found.

pom.xml (Spring Boot 3.5.x style)

<parent>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-parent</artifactId>
    <version>3.5.10</version>
</parent>

<properties>
    <java.version>21</java.version>
</properties>

<dependencies>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-web</artifactId>
    </dependency>
    <dependency>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-test</artifactId>
        <scope>test</scope>
    </dependency>
</dependencies>

<build>
    <plugins>
        <plugin>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-maven-plugin</artifactId>
        </plugin>
    </plugins>
</build>

In Spring Boot 4 some starters were renamed because the code base became modular. For example the web starter is called spring-boot-starter-webmvc. Always generate your pom from start.spring.io for the version you choose.

Step 2: Write a controller

package com.example.demo.controller;

import java.util.Map;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class GreetingController {

    @GetMapping("/greet/{name}")
    public Map<String, String> greet(@PathVariable String name) {
        return Map.of("message", "Hello, " + name);
    }
}

Step 3: Run it

./mvnw spring-boot:run                       # run from source
./mvnw clean package                        # build the jar
java -jar target/demo-0.0.1-SNAPSHOT.jar    # run the jar
curl http://localhost:8080/greet/Ram        # {"message":"Hello, Ram"}

application.properties basics

spring.application.name=demo
server.port=8081
server.servlet.context-path=/api
spring.devtools.restart.enabled=true

With context-path=/api the URL becomes http://localhost:8081/api/greet/Ram.

Spring Boot DevTools

DevTools restarts the application automatically when a class changes, and enables LiveReload for the browser. It is disabled automatically when you run the packaged jar, so it is safe to keep in the project (as an optional runtime dependency).

Common mistake: Placing the main class in a deep sub-package such as com.example.demo.app. Controllers in com.example.demo.web are then not scanned and you get 404 errors.

Interview questions

Why does my application start on port 8080?

8080 is the default port of the embedded Tomcat. Change it with server.port in application.properties.

What does the Maven wrapper (mvnw) do?

It downloads the correct Maven version automatically, so everybody builds the project with the same Maven.

How do I run the application in the IDE?

Run the main method of the class that has @SpringBootApplication.
